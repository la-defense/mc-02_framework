# 云台模式与输入

## 初始化

`GimbalInit()` 登记 yaw、pitch 两个 DJI 电机和云台命令／反馈话题，并取得 INS 姿态数据对象。它在 RTOS 启动前由整车初始化调用；成功后才由 `RobotTask()` 周期调用 `GimbalTask()`。电机初始化会先设为停止，注册本身不会使能电机。

## 模式行为

云台命令话题最多保留 50 ms。`GimbalTask()` 每轮读取一份新命令；读取为空、过期或失败时会清掉本地命令，随后按 `GIMBAL_ZERO_FORCE` 处理。

| 模式／条件 | 电机动作 | 参考值 | 反馈来源 |
|---|---|---|---|
| `GIMBAL_ZERO_FORCE` | 请求停止 yaw、pitch，并把两者参考清零 | 0 | 不用于本轮控制 |
| `GIMBAL_GYRO_MODE` | 使能 yaw、pitch；设置角度环和速度环 | 命令中的 yaw、pitch 以度传入，换成弧度后设置 | 两环均选择外部 IMU |
| `GIMBAL_FREE_MODE` | 与 `GIMBAL_GYRO_MODE` 相同 | 同上 | 同上 |
| 未知模式 | 与停止分支相同 | 0 | 不用于本轮控制 |
| 命令读取失败或超过 50 ms | 本地命令清零，因此进入停止分支 | 0 | 不用于本轮控制 |

当前 `FREE` 还没有独立的底盘跟随逻辑。不要依据模式名称推断它会读取电机编码器；生产配置和运行分支都选用外部 IMU。反馈回调将 yaw 总角度、pitch 角度、Z 轴陀螺仪速度和 X 轴陀螺仪速度分别作为弧度、弧度每秒数据提供，反馈来源允许 5 ms。

`DJIMotorStop()` 设置软件停止标志；电机控制任务据此把对应发送槽清零。`GimbalTask()` 返回不表示 CAN 报文已发送，也不能证明电机机械运动已经停止。

状态转换回归直接调用生产 `GimbalTask()`，检查电机接口调用、反馈来源和度到弧度换算；它不连接电机，也不验证实际转向、CAN 发送或机械运动。详见 [APP-09 记录](../../docs/workflow/tickets/APP-09.md) 和 [学习笔记 23](../../docs/学习笔记/23-Ozone辅助PID调参.md#云台模式的实际行为app-09)。
