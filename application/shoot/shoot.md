# shoot



## 工作流程

初始化3个电机，包括发射的2个 M3508 和拨盘 M2006。M2006 初始化时设置为速度闭环，防止上电乱转。当前只订阅 `shoot_cmd`。此前的 `shoot_feed` 没有任何字段，零长度话题会被消息中心拒绝，导致 `RobotCMDInit()` 失败；在没有真实反馈字段前不注册占位话题。

1. 从shoot_cmd获取消息
2. 根据工作模式确定是否急停
3. 如果之前是单发模式或3发模式并且冷却时间没到，直接结束本次任务，等待下一次进入
4. 如果已经冷却完成，根据发来的拨盘模式，设定m2006的闭环类型和参考值
5. 根据发来的弹速数据，设定摩擦轮的参考值
6. 根据发来的弹舱数据进行开合
7. 当前没有发射反馈话题；需要新增反馈时先定义有实际含义、非零长度的数据结构，再单独验证注册和发布路径。

发射命令通过带 50ms 新鲜度的消息快照读取。命令过期时三个电机失能并清零参考值；过期后的单发/三连发必须先收到新的 `LOAD_STOP`，避免旧触发在通信恢复后重放。相关生产回归见 [R25-11](../../docs/workflow/tickets/R25-11.md) 与 [MC02-0052](../../docs/workflow/tickets/MC02-0052.md)。
