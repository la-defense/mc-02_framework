# MC02-0062：USB 传输、生命周期与有限自动恢复

任务状态只维护在 [.Doc/TODO.md](../../../.Doc/TODO.md)。本文记录实施依据和验证证据，不能代替清单中的验收状态。

## 本轮范围与使用条件

从 `d40a8c05b1e9be65ea77d5a760bb94d776992247` 建立 `feat/usb-lifecycle`。WSL 运行主机测试，ARM 构建沿用五类角色的 Debug／RelWithDebInfo。裸板保持禁热、无执行器；LCD 相关工作按用户要求暂缓。

保留 SP 命令29字节和状态43字节、生产 CRC 及原安全许可。USB 接口使用自有 C 类型；接收中断复制，任务解析；发送复制到唯一在途缓冲，忙时立即拒绝，下一周期重新组装最新状态。

接收队列8项，每块最多128字节；超长整块拒绝。每轮最多派发4块／512字节。原接收时间、连续性编号及连接代号随块传递。丢块、过期或生命周期变化清残帧；50ms来源边界允许，读取不续期。

## 已确认的恢复规则

- 发送达到100ms未完成即失败；已启动报文不自动重发。
- 连续故障最多3次 USB 重建。开始重建即消耗一次，重新枚举不清次数。
- 连续60秒命令年龄始终不超过50ms、发送完成持续推进，且无生命周期中断／传输错误，才补满3次额度。
- 额度耗尽不再主动重启；后端仍可响应主机时，允许主机重新配置恢复通信，保留次数。无法确认停止时保持隔离，等待系统重新初始化。
- 初始未连接及普通业务停更不触发重启。重启清旧命令，恢复后等待新命令，仍由既有 safety 决定许可。
- 停止后软断开至少250ms，主机配置等待最多5秒，重建尝试之间至少1秒；等待分步推进，不在控制任务或中断中重建。
- 复用 defaultTask 处理 USB 生命周期；核对其栈余量。临界区仅用于有界复制和状态变更。

当前 HAL_PCD_Stop 会忽略 FIFO 清理结果，不能只凭 HAL_OK 复用缓冲；本轮须核对端点／中断及 FIFO 停止结果。USB 恢复失败不进入 Error_Handler 或主动整板复位。

## 验证与交付要求

生产接口测试覆盖容量、复制、每轮预算、分块、多帧、丢块、原时间、连接代号、真实完成、超时、停止失败、恢复额度及线程交错。Release 检查始终执行，各场景10秒超时；适用时运行 ASan／UBSan。

软件通过后提交准确 SHA，再核对裸板供电／VIN／电流，备份校验整片 Flash 与参数区。普通禁热固件及仅 bench_safe/single 允许的有限 USB 诊断固件分别 verify；诊断结束恢复普通固件。记录5轮 USB 拔插、有限完成通知丢失测试及正常60秒观察。软件注入不称真实硬件挂死，PC时间戳不称线端波形。

生成保护采用 USER CODE 最小接入和人工 CubeMX 核对；独立诊断 UART 由 MC02-0004 跟踪，新版协议／对时由原任务跟踪。实质更新学习笔记16及索引、USB和视觉说明，保存测试、资源、固件和裸板证据。全部验收前不关闭本任务。
