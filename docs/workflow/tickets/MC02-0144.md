# MC02-0144：受限调试固件的软件入口

任务状态和完整验收条件以 [TODO](../../../.Doc/TODO.md) 为准。此处记录构建边界与仍需接入的内容。

## 观察入口

`MC02_PROFILE=commissioning` 和 `MC02_COMMISSIONING_TARGET=observe` 生成独立命名的观察固件。它沿用裸板的禁热和不驱动执行器路径，但生成配置、健康接口与产物名称使用独立的调试身份。可选择已有的遥控观察功能；该功能不请求 READY。

观察固件不启用底盘、云台、发射、命令和电机控制，三路受控电源保持关闭。当前构建仍包含已有的视觉接收功能，但它不能取得运动授权。观察身份不表示允许实车通电或动作，现场条件另行确认。

## 运动入口的前提

`chassis`、`gimbal` 和 `both` 目前明确拒绝构建。后续需完成对应模块选择、人工来源和安全许可接线、故障撤销，以及所选电机的真实输出上限和机械参数确认。云台运动还需要可用的三轴控制。不能通过临时测试数值将车型参数标记为已确认；这些入口的拒绝不能替代最终实现。

四轮底盘共用车型配置中的 `dji_chassis_output_limit_raw`。整车运动固件在申请设备前检查该值，DJI 驱动在全部控制环和安装方向换算结束后限制报文中的最终值。这个字段使用电调原始命令单位。哨兵目前填零表示待确认，受限运动仍需接入自己的构建与人工许可路径。

本机配置、源码和 ELF 检查见[验证记录](MC02-0144-evidence/README.md)。上板和上车观察、实物方向及停止表现属于另行确认的现场验收。
