# MC02-0041：裸板配置与引脚隔离验收

基线为 `2c28346`，沿用相关修复分支。任务状态只保存在 [.Doc/TODO.md](../../../.Doc/TODO.md)。关联 MC02-0038（底层关断）、MC02-0039（锁存恢复）、MC02-0045（可信 IMU）；物理供电验收仍由 LCD-09 跟踪。

## 修复与兼容范围

- `Core/Src/tim.c` 的 `HAL_TIM_MspPostInit()` 在 TIM3 的 CubeMX 用户保护区域处理禁热分支：启用 GPIOB 时钟，先将 PB1 锁存值写低，再配置为推挽 GPIO 后返回。重复初始化执行相同顺序，避免后面的自动生成代码将 PB1 改回复用模式。
- 启热分支继续使用 AF2/TIM3，仅在主机模拟中验证。四个真实固件构建都使用 `MC02_ENABLE_HEATER=OFF`。
- 核对现有裸板隔离：`robot_def.h` 不定义整机应用宏；`RobotTask()` 只维护安全状态和视觉发送；`MotorControlTask()` 每周期仍消费 CAN/UART/VCP 队列，但不调用电机控制。GPIO 初始化先关闭 PC13/14/15 的闲置电源；未注册模块的电机摘要先清零。
- 公共接口、43/29 字节 SP 帧及参数 A/B 格式未改动。

## 主机证据

新增测试直接联编生产 `Core/Src/tim.c` 与 `modules/motor/motor_task.c`，只替代 HAL、总线与输出边界。生产 TIM 回调修复前，bench_safe 禁热和 robot 禁热均失败，模拟启热通过；修复后验证先低电平再输出模式、重复初始化及 TIM12 未受影响。MotorControlTask 两周期后模拟队列均消费完成；裸板输出调用为零，整机维持控制调用。

2026-10-09 软件验证：完整主机 Debug/Release 各 59/59 通过；工具测试 17/17、TODO 格式检查通过。bench_safe/robot 的 Debug/RelWithDebInfo 四个新目录构建均通过、均禁热，四个 ELF 隔离检查通过；bench_safe 启热配置被明确拒绝。新建 Release 目录还暴露通用 DWT 测试桩缺少生产全局变量声明；只补声明，不改变看门狗生产实现。

Debug 日志 `build/host-tests/mc02-0041-debug-results.log`；Release 日志 `build/host-tests-0041-release-results.log`；固件构建与 ELF 检查日志为 `build/mc02-0041-{bench_safe,robot}-{debug,rel}-{build,elf-check}.log`。bench_safe Debug ELF 为 `build/mc02-0041-bench_safe-debug/Basic_Framework_MC02_bench_safe.elf`，SHA-256 `9F30E007C1747E68C1708E7BD780182395944F6B84BA1679D6156EFBC68E39D9`；非空 Flash 加载范围为 `[0x08000000, 0x08028060)`，未触及参数区。代码提交 SHA 在板上证据中补录。

用户本轮确认：只有开发板、LCD、USB 与调试器；12.5V、限流 2A、约 0.09A，CV 亮、CC 不亮，无异常。初次设备枚举只有调试器 COM9，板载 COM14 不在 Windows/usbipd 已连接列表；正在等待确认开发板 USB 数据连接，未因此切换到调试器串口。

## 板上验收约定

软件提交后记录代码 SHA、ELF 哈希与准确配置。重新确认裸板连接和限流供电；新备份 1MiB Flash 与 `0x080c0000–0x080fffff` 参数区，确认 ELF 加载及实际擦除范围不重叠参数区。直接 OpenOCD 烧录 bench_safe Debug 并 verify，Tcl 使用正斜杠路径；回读参数逐字节比较。

运行 60 秒，在开始、中段和结束读取运行态 IMU/通信快照。一次性固定白名单只读 PB1、PC13/14/15 与 TIM3 必要寄存器，现有工具 RAM 白名单不扩展。确认推挽输出低锁存、CCR4/CC4E/CEN 均为零。

只启用一个 COM14 客户端，以 200Hz 发送准确 1000 个 `mode=0`、六个浮点值为零的中性指令；检查接收计数增量、CRC 计数和时间戳。停发至少 100ms 后检查整个接收帧及时间戳清零。连续接收状态帧验证 CRC 和四元数有限；用户确认 LCD 显示 SAFE BENCH、刷新正常、电机未注册摘要为零或离线。

连接、烧录、校验或只读检查失败均保留日志并停止，不自动重试或转入停核/复位。全部软件及上述板上条件满足才关闭 TODO；寄存器输出锁存低不等于 PB1 实际电平已测量。
