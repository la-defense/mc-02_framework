# MC02-0063：H723 分区 Flash 驱动

任务状态只维护在 [.Doc/TODO.md](../../../.Doc/TODO.md)。本文记录实现范围和验证证据，不代替 TODO 状态。

## 范围与接口

从基线 `c36e5eaeee02b3961d42829c44217aca45c9e235` 建立 `feat/h723-flash-partitions`。本轮仅做 WSL 主机模型测试和 ARM 构建，没有连接开发板或写入真实 Flash。

应用区为 `0x08000000–0x080C0000`，参数 A 为 `0x080C0000–0x080E0000`，参数 B 为 `0x080E0000–0x08100000`。链接脚本给出边界符号并检查连续性、扇区大小和 H723 1MiB 末端；驱动每次读取布局时再核对这些符号，不匹配就拒绝操作。

公开接口见 [bsp_flash.h](../../../bsp/flash/bsp_flash.h)：读操作使用“分区＋字节偏移”，应用区默认只读；参数擦除按128KiB扇区，编程按32字节 Flash word，写入源须为对齐的 RAM 数据且不能位于 Flash 区域。越界、错误对齐、非法分区、未授权、错误上下文，以及 HAL 错误／忙／超时均返回不同状态。写入失败时已完成的前缀不自动回滚。

授权类型保持不透明，具体结构与创建／关闭入口只在 [内部头文件](../../../bsp/flash/bsp_flash_internal.h) 提供给参数实现。`ParamCommit()`、`ParamReset()`先调用 MC02-0036 注册的加热与 TaskMonitor 准入，再取得写入令牌；起始时间在回调前读取，整个操作共用8秒期限。ISR 在调用任务级回调前拒绝。缺失回调、拒绝、超时或 Flash 操作失败不继续后续擦写；原有看门狗恢复和 A/B 回退方式保留。

`ParamReset()`顺序擦除 A、B，共用一个授权时限；若中途失败，Flash 可能部分擦除，但 RAM 参数和活动记录状态保持原值。正常保存仍先写非活动区，再回读比较，只有成功后切换活动区和序号。

## 主机验证

生产接口回归位于 [param_operation_test.c](../../../tests/host/param_operation_test.c)；它通过固定映射模拟完整1MiB地址空间。错误链接布局由 [bsp_flash_invalid_layout_test.c](../../../tests/host/bsp_flash_invalid_layout_test.c) 使用错误符号单独链接生产驱动，验证查询失败不覆盖原输出，也不会进入擦写入口。

专项用例覆盖：应用只读、A/B 分区和边界、零长度读取、参数读写的范围与对齐、Flash 源数据拒绝、未提供授权、ISR 调用拒绝、维护回调拒绝、Flash 解锁／擦除／编程错误／忙／超时、8秒到期、毫秒计数回绕、旧记录 CRC 成功／失败、写后回读、A/B 交替和 `ParamReset()` 第二扇区失败时的 RAM 保留。检查使用显式宏，Release 下仍然执行；各 CTest 项目限时10秒。
