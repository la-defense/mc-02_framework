# R25-07：修复底盘跟随计算与速度限幅

任务状态只见 [.Doc/TODO.md](../../../.Doc/TODO.md)。基线 `2b3a041949b6678ef6fa252faa5dacaf4a500b18`，沿用 `fix/mc02-0045-bmi088-init`；本轮纯软件，不烧录。

## 实施

- 将底盘计算提取为无硬件副作用的生产接口 [`chassis_motion.c`](../../../application/chassis/chassis_motion.c)。角度跟随使用 `-1.5f * offset * fabsf(offset)`，限幅底盘角速度；显式配置小陀螺目标角速度，移除固定 `4000 deg/s`。
- 输入单位固定为 `vx/vy: mm/s`、`offset_angle: deg`、`wz: deg/s`。几何尺寸和减速比必须为有限正数，偏置必须有限；命令四个浮点字段有限，角度处于 `[-180,180]`。
- 保持现行麦克纳姆符号、坐标旋转及线速度到电机轴 `deg/s` 的换算。四轮超过电机轴转速上限时使用共同缩放系数，比例和方向保持一致；报告的角速度也按同一系数反映实际输出。浮点舍入使单个输出略超上限时，把共同缩放值退一格再重算。
- 在 `robot_def.h` 增加底盘限值配置；生产默认配置未就绪、数值为零。配置无效、输入不合法、模式未知或中间结果非有限时计算失败、输出全零。`ChassisTask()` 只有校验和计算成功后才写四个参考值并使能；零力及失败路径停止四轮并清零旧参考。
- SP 43/29 字节帧、CRC、参数布局不变。

## 回归

先在计算接口占位实现和旧 `ChassisTask()` 行为下运行新测试，分别复现“跟随计算没有输出”和“停止后旧电机参考未清零”。生产实现后回归转绿。生产计算测试覆盖：`±0.5°` 得到 `∓0.375 deg/s`、方向/零点、角速度边界、小陀螺向量、前进/横移/混合麦轮向量、轴速换算、共同限幅比例、缺配置、非法几何/限值、未知模式、四个命令浮点字段的 NaN/Inf、越界角度和有限极值导致的溢出。生产 `ChassisTask()` 联编真实消息中心，验证配置已就绪时设定有界四轮目标、先写完整目标再使能；未配置、零力、未知模式及非法角度均停止且清零，之后有效命令重新计算。RobotCMD 既有测试继续覆盖 SAFE/CALIB/FAULT/ESTOP 发布零力。

六种固件构建目录前缀 `build/r25-07-{bench,robot,rcdiag}-{Debug,RelWithDebInfo}`，全部 `MC02_ENABLE_HEATER=OFF`。三种 profile 的两个优化等级构建成功；`check_firmware_profile.py` 的 bench_safe/robot/rcdiag ELF 检查通过。`bench_safe + heater ON` 和 `robot + rcdiag ON` 配置均被 CMake 拒绝。详细构建日志存于同一 `build/` 前缀。各目录通过 `-DMC02_PROFILE=bench_safe|robot` 选择 profile；rcdiag 另加 `-DMC02_BENCH_RC_DIAGNOSTICS=ON`，并统一使用 `-DMC02_ENABLE_HEATER=OFF`。本机 `build-cmake` skill 脚本因缺少 `tool_config`、`profile_store` 导入依赖而无法启动，等价的 CMake/Ninja 命令在 WSL 完成了六种构建。本轮没有推送，因此没有远端 CI 结果；现有 GitHub Actions 使用同一 host CTest 目录，会自动发现新增测试。
