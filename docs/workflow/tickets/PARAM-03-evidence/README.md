# PARAM-03 本机验证

## 车型配置与 Flash 预留编号

- 修复前，用生产参数实现加载一条带有效标定的旧 A 区记录。通用读取能返回 CAN 预留编号的原始值，新增回归因此失败。修复后，接口拒绝读取或写入 CAN、底盘两个预留段，读取失败时保留调用者原值。
- 回归覆盖两个编号段的首尾、段内新键以及相邻编号。旧记录里的 BMI088 标定仍按逻辑 v1 读取。另存两个普通参数后，测试逐字节比较原 A 区和新 B 区中保留的旧条目，并检查只有两个普通参数增加到有效载荷中。
- 参数组事务、A/B 回退、CRC 拒绝、Flash 维护授权、布局和下层失败处理共 13 项通过 ASan／UBSan。参数操作使用生产接口和主机模拟 Flash。
- `verify.py --fast --host --firmware --presets bench-debug,rcdiag-debug --parallel 1` 通过。WSL Debug 和 Release 各通过 859 项，两种禁热固件通过 ARM 构建、源码和 ELF 检查。相对 `8d2aff9`，普通禁热固件的 Flash 和主 RAM 保持 257776 B、115576 B，遥控诊断保持 261432 B、116088 B。两种 ELF 均保留 BMI088 参数组接口，通用读写接口因无调用未链接。六种正式预设仍因未确认核心条件按预期拒绝构建。
- 车型的真实轮组、电机与机械参数仍待 APP-10 确认。本轮没有实际 Flash 擦写或硬件试验。
