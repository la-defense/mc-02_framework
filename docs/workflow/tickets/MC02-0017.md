# MC02-0017：DJI 电机实例反馈滤波

本页记录实现与验证证据；唯一任务状态由 [.Doc/TODO.md](../../../.Doc/TODO.md) 维护。

基线：`445dfa28338c0a4c8b2d6e9ebe0531c742b1e394`。分支：`feat/dji-feedback-filter`。

## 实现范围

- `DJIMotorInit()`继续作为兼容入口，速度逐帧系数为0.85，电流为0.9；保留旧整数电流反馈每帧截断行为。
- 新增`DJIMotorInitWithFilter()`，速度和电流可分别选择逐帧兼容、使用真实秒单位`dt`的一阶时间常数低通，或关闭滤波。每实例复制配置并保存独立历史；`tau_s`、`dt_min_s`、`dt_max_s`单位为秒，间隔边界允许，最大间隔不超过50ms。
- `CANRxItem_t`在接收中断入队时同时保存HAL毫秒与DWT周期戳；派发时一并复制到`CANInstance`。DJI滤波使用周期差，毫秒差用于发现周期计数单圈范围外的长停顿，不以任务派发时刻替代帧到达时刻。
- 缺样、异常`dt`或计算失败撤销对应滤波有效标记并保留最后数值。恢复样本重建滤波历史。Daemon继续独立检查新鲜度；内部速度／电流被实际控制环使用且无效时，丢弃本轮PID输出、清除PID历史并输出零。外部速度环不依赖内部速度滤波状态。
- `DJIMotorSummary_t`新增原始值、浮点有效电流、真实反馈间隔、样本计数及滤波状态。原始DJI电流仍是协议数值，不换算为安培。

## 验收向量和覆盖

生产解析器主机测试使用真实`DecodeDJIMotor()`回调及CAN接收实现，硬件层由HAL／DWT／Daemon替身支持。

| 用例 | 检查 |
|---|---|
| 兼容模式 | 10RPM→51deg/s、100→90电流；下一帧20RPM→109.65deg/s、200→189整数电流；原始值和Daemon刷新次数正确 |
| 时间常数 | `tau=10ms`，首帧输出60deg/s／100；`dt=1ms`后65.454544／109.09091；再以`dt=2ms`输入零得到54.54545／90.90909 |
| 周期时间戳 | `0xFFFFFF00`到`0x00075200`的32位回绕差为480000周期（480MHz下1ms）；毫秒戳相同仍得到有效亚毫秒来源时间 |
| 间隔边界 | 验证10us下界、50ms上界、上下界外拒绝、旧数值保留及下一帧重建 |
| 缺样恢复 | Daemon离线时滤波失效且本周期输出零，不额外刷新Daemon；下一份CAN帧恢复有效 |
| 通道和实例独立 | 同一实例速度时间常数／电流旁路混合配置；不同实例逐帧与旁路交错；外部速度环在内部速度未有效时仍可运行 |
| 参数与帧检查 | NaN时间常数、倒置dt范围及非法模式在注册CAN前拒绝；非8字节帧不刷新Daemon或样本计数 |

CTest场景为`legacy`、`time-constant`、`bypass`、`gap`、`missing`、`multi-instance`、`bounds`、`channels`、`config`，每项10秒超时并使用Release持续生效的`TEST_CHECK`。

## 工程验证

本机仅使用WSL主机测试和ARM固件构建，没有进行Windows原生构建，也没有连接开发板或真实电机。

- WSL GCC 11.4.0：Debug与Release全量CTest在最终代码上各355/355通过；9个反馈滤波场景在Debug、Release及ASan／UBSan下均通过。
- ARM GCC 10.3.1：`bench-debug`、`bench-rel`、`rcdiag-debug`、`rcdiag-rel`、`robot-single-debug`、`robot-single-rel`、`robot-chassis-debug`、`robot-chassis-rel`、`robot-gimbal-debug`、`robot-gimbal-rel`全部构建通过。十个ELF的配置隔离检查通过，属性均为Cortex-M7、FPv5-D16及hard-float；编译数据库含`-mfloat-abi=hard`和`-mfpu=fpv5-d16`，未启用`-ffast-math`。
- 同工具链基线比较中，Flash增量按`.text + .data`计算，静态RAM增量按`.data + .bss`计算。各构建配置的`.bss`不变；bench_safe与rcdiag的静态RAM增加384字节，robot角色增加420字节。DJI实例由动态分配，DWARF记录的`DJIMotorInstance`从基线504字节增至760字节，每实例增加256字节。

| 固件 | Flash增量（字节） | 静态RAM增量（字节） |
|---|---:|---:|
| `bench-debug` | +536 | +384 |
| `bench-rel` | +544 | +384 |
| `rcdiag-debug` | +536 | +384 |
| `rcdiag-rel` | +544 | +384 |
| `robot-single-debug` | +8948 | +420 |
| `robot-single-rel` | +8540 | +420 |
| `robot-chassis-debug` | +8940 | +420 |
| `robot-chassis-rel` | +8548 | +420 |
| `robot-gimbal-debug` | +8952 | +420 |
| `robot-gimbal-rel` | +8572 | +420 |

`rel`使用RelWithDebInfo。Debug与RelWithDebInfo的编译优化和链接布局会影响`.text`大小；表中差值不能直接解释为滤波代码本身的精确体积。验收覆盖计算路径、配置隔离和固件构建，不证明实物CAN采样抖动、电机响应或滤波参数适配。
