## 验收记录

- 固定 A5 向量：`a5 06 00 99 45 23 34 12 00 00 80 3f 78 7b`，表示编号 `0x2345`、标志 `0x1234`、一个 `1.0f`，14字节。历史兼容测试还覆盖头／尾CRC失败和解析失败时输出保留。
- CMake 固件仅收集 `bsp/`、`modules/`、`application/` 下的 C 源码；Makefile 显式清单也已移除归档实现。主机测试从归档目录显式编译源文件，设置10秒超时并标记为 `historical`。
- `check_cmake_regeneration.py` 的隔离副本包含归档目录，并核对基线编译数据库与 Ninja 链接命令均不含归档实现。
- WSL Debug／Release 全量主机测试均通过，分别为280/280；历史 A5 兼容测试使用生产 CRC，验证固定完整帧、头／尾 CRC 失败及解析失败时输出保留。
- bench_safe、robot、rcdiag × Debug／RelWithDebInfo 六种禁热 ARM 固件构建及 profile 检查通过。六份编译数据库、实际链接输入和 ELF 均不含归档源码；旧构建目录虽留有迁移前对象文件，增量重链接也未将其带入链接或 ELF。
- 六种构建均使用 `fpv5-d16`／hard-float ABI、未启用 `-ffast-math`；严格格式选项检查通过。与同工具链任务前基线相比，text／data／bss 均无变化：bench_safe Debug `195136/3172/107928`、RelWithDebInfo `186272/3172/107880`；robot Debug `225480/3984/115736`、RelWithDebInfo `214528/3984/115712`；rcdiag Debug `197364/3172/111096`、RelWithDebInfo `188392/3172/111048` 字节。
- CMake 增量发现回归通过，隔离副本包含 `docs/history/seasky/`，基线和各构建阶段均排除归档实现；bench_safe 加热配置及 robot 裁判诊断非法组合均被拒绝。TODO格式、受影响文档的910条本地链接和 `git diff --check` 均通过。
- 固件未引用旧模块，链接器原本即可回收其未引用实现，因此不把体积变化作为验收条件。bench_safe 构建仍报告既有 `chassis.c` 未使用变量警告，本任务未改动该处。
