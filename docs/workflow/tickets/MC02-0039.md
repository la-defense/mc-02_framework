# MC02-0039：加热故障锁存与恢复条件

关联任务：MC02-0034（调试停核与加热安全）、MC02-0036（标定／Flash 长操作）、MC02-0037（可信 VIN 快照）、LCD-09（受控供电验收）。唯一任务状态见 [.Doc/TODO.md](../../../.Doc/TODO.md)。

## 修复约定

- IMUHeaterClearFault() 返回 1 表示所有恢复检查通过，返回 0 表示拒绝；无故障时也走相同检查。每次调用先清零 PWM 和 PID 积分，并重新读取 ADC 快照，不访问 SPI。
- 接受的 IMU 样本必须已初始化、有效、温度有限且在 [-20, 80]°C 内，年龄不超过 5ms。清除锁存要求温度严格低于 42°C；>=50°C 立即锁存过温。
- 接受的 ADC 样本必须有效、换算配置有效、年龄不超过 20ms，VIN 在 10–30V 闭区间。越界高压会锁存；低压或无效快照只禁止输出。
- 锁存后必须取得故障发生之后的更新样本。重复／回退序号、过期样本以及过期操作样本均不能用作恢复证据。清除成功时输出仍为零，另需清除之后的新 IMU 样本才可进入控制。
- force-off 请求、活动中的长操作、失败锁定或等待操作后新样本时拒绝清除。清故障不清除长操作失败掩码。
- 连续非零 PWM 达到 300000ms（5分钟）锁存；无效温度连续达到 500ms 锁存。计时使用独立 active 标志与无符号差值，覆盖 tick=0 和回绕。
- 禁热构建继续采样和判断故障，物理 PWM 固定为零；现有 5% 占空比与 VIN 功率限制保留。无新增 LCD、串口或遥控清除入口。

## 裸板回归边界

只使用裸板、LCD、USB 与调试器；开始烧录前重新确认实际供电和连接。目标是新建的 bench_safe Debug ELF，配置 MC02_ENABLE_HEATER=OFF。先备份并散列 1MiB Flash 和 0x080c0000–0x080fffff 参数区，确认 ELF 的 Flash load 范围不触及参数区，再直接调用已验证的 OpenOCD 编程与 verify 命令，不做整片擦除。烧录后参数区逐字节比较。

运行 60 秒，在开始、约 30 秒和结束时用匹配 ELF 的只读快照观察 BMI088 ID／READY／有效样本、加热占空比与复位迹象；全程仅被动接收 COM14 状态帧，核验 CRC 和有限四元数。快照失败不转为 halt／reset 调试，连接或编程／校验失败时保存证据并停止。此实板验收不注入过温、不打开加热，不验证供电轨、PB1 实际电平、VIN 精度或温升；这些仍由 LCD-09 跟踪。
