# MC02-0090：上下位机对时与时间映射

任务状态只在[TODO](../../../.Doc/TODO.md)维护。本轮共用分支 `feat/vision-time-sync`，基线 `122e3ff27f41716388a2fe07e82dfecb21d4625e`。验收限定为 WSL 主机测试和 ARM 固件构建，不连接开发板；上位机生产适配留待后续。

## 已确定的交互

MCU 主动发送 V2 `0x83` 探测，PC 以 `0x03` 回应。探测负载是非零请求编号；回应负载是请求编号和 PC 收到探测时刻 T2，回应帧头来源时间提供 PC 发出回应时刻 T3。MCU 以探测帧来源时间记 T1，以完整回应帧最后字节所在接收块的原始时间记 T4。单请求在途，默认每 500 ms 探测一次，响应期限 100 ms，最大 RTT 50 ms；连续三份有效样本后映射有效，2 秒没有新样本后失效。边界允许。

偏差定义为 `PC 时钟−MCU 时钟`，样本使用 `((T2−T1)+(T3−T4))/2`。往返时间为 `(T4−T1)−(T3−T2)`。计数按32位毫秒回绕；半周期歧义、逆序、超期限、超 RTT 和非当前 USB 代号的回应不会进入样本。连续映射偏差跳变超过50 ms时清空窗口并重新收集三份样本。业务新鲜度继续按本机原始接收时刻判断，对时和转换不延长业务期限；SP 协议不提供虚构的来源时刻。

## 实现入口

- [时间映射接口](../../../modules/time_sync/time_mapping.h)和[实现](../../../modules/time_sync/time_mapping.c)：纯 C、调用者持有实例，无 HAL／RTOS／动态分配；提供初始化、重置、四时刻样本、只读状态和显式远端转本地转换。
- [V2协议接口](../../../modules/master_machine/vision_protocol_v2.h)：固定类型、长度、小端字段和生产 CRC；解析结果同时保留首字节接收时刻与末字节完成时刻。
- [视觉链路接口](../../../modules/master_machine/master_process.h)：`VisionGetTimeSyncSnapshot()`复制状态，`VisionMapRemoteTime()`失败保留输出。V2 仅在 USB/UART 传输可用时运行探测；SP 返回不可用。
- 时间映射不自动重写消息中心来源时钟，也不作为 V2 控制输入恢复的门槛。连接代号变化会清除映射，超时后按固定周期重新探测。

## 本机验证

主机测试直接链接生产编解码、映射器和 `MasterProcess`。覆盖探测／回应固定字节、所有接收切分点、T4 时间、正负偏差、计数回绕、最大RTT与交换期限边界、偏差跳变重获、2秒有效边界和失败输出保留。集成测试模拟 USB Ready 和 PC 回复，覆盖单请求、500 ms 探测周期、100 ms 边界及超时、无效请求号、旧连接回应、三样本建立／失效／重连恢复，并断言对时回应不刷新业务接收计数、Daemon 或 USB 合法命令计数。
