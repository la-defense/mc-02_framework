## 数学与失败行为

实现使用带遗忘因子的递推最小二乘：

```text
d = lambda + xᵀ P x
K = P x / d
e = y - xᵀ theta
theta_new = theta + K e
P_new = (P - K xᵀ P) / lambda
```

增益 K 与残差 e 分开保存，协方差更新使用未乘残差的 K。零输入仍按 lambda 更新协方差；零残差不改变参数，但仍执行协方差递推。候选参数和协方差先写入工作区临时区，协方差取对称平均后用 double LDLᵀ 检查严格正定。全部检查通过后才提交参数、P、K、预测值、残差和成功计数。

矩阵函数失败、分母异常、非有限输入或结果、候选P非正定时返回错误。失败会保留上一份已提交状态，允许后续合法样本继续。Reset 完整清零旧协方差及计算数据，再将 P 设为 delta 对角阵并保存新的初始参数。读取接口会先检查容量、对齐和所有输出范围重叠，失败不改输出。

## 验证

- 独立 Householder QR 将带遗忘权重的历史样本与初始先验一起求解，逐样本对照参数、P、增益、预测和残差；容差为绝对 `5e-5` 加相对 `5e-4`。
- 固定标量问题验证零残差仍更新P；另测 lambda=0.5 下连续零输入时P按遗忘因子增长。
- 工作区验证覆盖查询输出不变、准确大小／少1字节、错位、实例／输入／工作区重叠、输出别名、尺寸1、16和255、非法维度及重复重置。
- 失败验证覆盖配置范围、长度、NaN／Inf、乘积溢出、矩阵乘／减逐步失败、候选P非正定和失败后恢复；Linux 对初始化、更新、状态复制、重置包装分配器，调用期间未发现分配或释放。
- 不同维度实例交错；Linux 另以两个线程各更新独立实例2000次。所有检查使用 Release 下仍生效的 `TEST_CHECK`。

本机验证日志位于忽略目录 `build/mc02-0080/`。WSL Debug／Release 全量各127/127；Windows MinGW 支持子集各29/29。bench_safe、robot、rcdiag 三类配置的 Debug／RelWithDebInfo 六种禁热固件、六项 ELF/profile 检查通过；bench_safe 开启加热、robot 开启遥控诊断两种非法组合均被拒绝。`check_dsp_sources.py` 通过。

固件 RLS 对象的未定义符号只有 `arm_mat_mult_f32`、`arm_mat_sub_f32`、`memcpy` 和 `memset`，没有 HAL、RTOS 或分配器引用。Cortex-M7 编译使用 `fpv5-d16` 与 hard-float，不启用 fast-math。最终 ELF 未保留未调用的 RLS 入口；六种固件的 Flash/RAM 与 MC02-0099 基线相同：
