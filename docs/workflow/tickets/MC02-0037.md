# MC02-0037：可信 VIN 与按键 ADC 采样

本文件记录验收细节；任务状态只由 [.Doc/TODO.md](../../../.Doc/TODO.md) 管理。

## 问题

ADC DMA 原来只存一对数据，生产接口只检查 DMA 是否启动。DMA 停止或发生错误后，旧的 VCC_IN 读数仍可能被加热器当成当前电压。LCD 按键接口把“没有可用 ADC 数据”折算为原始值 0，而 0 又落在中键范围；按键按住期间如果采样失效，也可能把故障当成松开并执行动作。

## 实施

- `BSP_ADCGetSample()` 发布 VCC_IN 和按键的成对快照，带序号、完成时间、错误标志和电压配置有效标志；区分未就绪、有效、过期和错误状态。
- 移除返回裸 `0` 的无状态原始值和 VIN getter；调用者必须通过快照状态判断数据是否可用，避免将无效数据误认成中键或 `0.0V`。
- ADC DMA 使用 32 对循环缓冲区，启动前对齐清理并失效整块接收区，避免旧脏 cache line 回写覆盖 DMA 数据；半传输／全传输完成回调中分别处理已完成的 16 对，按 32 字节 cache line 对齐失效后再平均完整扫描对并发布。校准、DMA 启动或运行期错误均阻止样本被当成有效数据。
- 加热器只接受 20ms 内、配置有效、有限且在允许范围内的 VIN 样本；失效或过期即关闭 PWM。原始采样数据的状态与 VIN 换算配置分开，因此电压换算配置错误会拒绝加热，但不会伪造 ADC 传输错误。
- LCD 按键和在位检测都只读取新鲜快照。非新鲜 ADC 或不属于有效档位的输入会清除按键候选及按住状态，不生成松开事件；诊断页在采样不可用时显示 `raw:--`，VIN 行显示 `-- V`。

- `BSP_ADCGetSample()` 保持原签名和生产职责；新增 Daemon 任务调用的 `BSP_ADCUpdateDiagnostics()`，每 250ms 至少间隔记录一次生产 getter 的状态、原始 VIN／按键读数、序号、采样时刻、采集时刻、错误码、电压位形及换算常量。诊断记录采用 15 个连续 32 位字段和奇偶版本号，供匹配 ELF 的工具只读读取；它不参与加热许可，也不替代实时 getter。
