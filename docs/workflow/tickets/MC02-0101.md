# MC02-0101：双协议禁火测试帧与输入工具对齐

## 范围与决策

从基线 `25b682053cb9b97777e9ae834f6892cc8e3b2c4c` 在 `feat/vision-test-tools` 实施。本任务只调整本仓库的诊断工具、工具测试和教学说明，不改生产上位机，不建立整车回放，也不连接真实串口或执行器。

- `vision_sim.py` 支持SP固定帧与V2最小瞄准帧；端口必须显式提供，默认构造中立帧。
- 两种协议仅允许mode 0/1。SP mode 2请求供弹，工具拒绝；V2仅发不含开火字段的AIM_COMMAND。SP mode 1仍可能使能摩擦轮，因此禁火不等于无执行器动作。
- 六个瞄准数值从命令行度、度/秒、度/秒²转为线上弧度、弧度/秒、弧度/秒²；V2来源时刻使用单调毫秒，序号允许自然回绕。
- USB CDC波特率可能被忽略；端口打开错误、每次写入超时、短写和发送错误均报告并停止，不切换端口、不重试、不补发积压数据。
- DT7保留已验证设备身份、输入租约、两帧全松开握手及失败停止。实时标题显示显式端口；180秒只约束离线回放。

## 边界

主机固定向量只核对软件字节；不验证实际串口波形、视觉上位机互通、控制响应或机器人动作。mode 0是默认中立帧，SP mode 1不请求供弹但可能使能摩擦轮，实际使用时必须遵守裸板与执行器隔离边界。
