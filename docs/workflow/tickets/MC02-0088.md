# MC02-0088 固定周期与任务唤醒

任务验收和状态见 [TODO](../../../.Doc/TODO.md)。

周期配置用微秒表示。可移植计算接受计数器的实际刻度，要求周期和预算能精确表示。任务拿到第一拍后，后续计划时刻以固定间隔推进。迟到时领取最近已经到期的一拍，跳过更早的拍点。本轮执行预算和计划截止点分别检查。见[周期接口](../../../bsp/os/platform_periodic.h)。

FreeRTOS 适配器使用现有 32 位计数和绝对时刻等待。当前刻度为 1 ms，亚毫秒配置会被拒绝。正常裸板及受限观察配置的整车诊断任务从 TaskMonitor 放行后使用固定 5 ms 拍点。等待失败会停止该任务的进度上报，由现有监控处理。诊断中的耗时告警继续使用 DWT 测量。

独立任务的车型周期、硬件定时器唤醒、真实板上的调度时延和资源预算仍需完成。见[本机验证](MC02-0088-evidence/README.md)。
