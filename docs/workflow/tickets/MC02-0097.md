# MC02-0097：有界 LCD 绘图与刷新结果

任务状态只维护在 [.Doc/TODO.md](../../../.Doc/TODO.md)。实现分支为 `fix/lcd-bounds`，起始基线为 `ef22ac9c4e0d177e3223147223de9ec42d0194ce`。本记录分阶段保存软件与裸板证据，未完成的硬件检查留在本页待补。

## 实现范围

- `lcd.c` 集中面板初始化、SPI 发送、状态查询、顶层期限和恢复隔离；单次 HAL 发送最长2ms，初始化／完整恢复1000ms，清屏／静态页250ms，数值更新20ms。
- `lcd_buf.c` 只保留当前界面使用的清屏、含末端矩形、ASCII、中文字形、整数及浮点格式化；共享一条280像素的静态行缓冲，绘制入口接收显式字节数或字形数量并先检查完整输入。
- `lcd_ui.c` 先检查最终显示值再清理对应区域；只在本次清理、数字和单位均发送成功后更新该行缓存。错误会关闭背光、使界面和缓存失效；完整恢复成功才重新点亮。
- `lcd_task.c` 保留单显示任务、四页布局、现有稳定重新接入恢复和长按中键恢复。`MC02_BENCH_LCD_DIAGNOSTICS` 默认关闭，仅允许 `bench_safe/single` 禁热固件，复用 LCD 任务展示四张画面，每张15秒，结束后回到普通第0页。

页面／冻结所有权、故障页面和 ADC 在位算法仍分别由 LCD-14、MC02-0098、LCD-15 跟踪。SPI 成功只证明本机发送完成，不证明面板确认显示。
