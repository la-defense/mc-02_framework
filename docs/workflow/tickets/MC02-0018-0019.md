# MC02-0018、MC02-0019：LK 与 HT04 方向标志

本文记录 LK9025 与 HT04 对方向标志的统一位置和软件验收证据。TODO 状态只在 [.Doc/TODO.md](../../../.Doc/TODO.md) 维护。本轮使用 WSL 主机测试和 ARM 固件构建，不连接开发板或电机。

## 已实现行为

- 角度／速度外环沿用 DJI、XM 的规则：`motor_reverse_flag` 在 PID 前转换外层目标，`feedback_reverse_flag` 在所有 PID 与前馈后转换最终输出。
- LK、HT04 的默认 `NORMAL` 方向保持原有效行为；角度／速度外环的显式方向组合统一。
- 开环和电流外环保留旧输出端 `motor_reverse_flag` 行为，`feedback_reverse_flag` 不参与这些分支。
- LK 和 HT04 在申请 CAN、Daemon 等资源前拒绝非法方向枚举，不修改调用方配置。

## 固定回归

LK 生产闭环测试以角度 `10`、速度 `2`、目标 `30` 及不同 P 增益检查方向组合，核对生产 CAN 帧中的有符号小端值；角度外环正目标的固定答案为 `{3, -12, -3, 12}`，负目标为 `{-12, 3, 12, -3}`；速度外环正目标为 `{5, -10, -5, 10}`，负目标为 `{-10, 5, 10, -5}`。速度与角度外环均另验零目标。LK 与 HT04 生产任务测试还分别覆盖开环正／负／零参考、电流外环兼容和非法枚举初始化拒绝；HT04 按独立期望值检查12位力矩字段。所有测试替换硬件、时钟和任务调度边界，不连接真实电机。

## 验收记录（2026-10-24）

- WSL Ubuntu 22.04／GCC 11.4：主机 Debug 全量 CTest **346/346** 通过；Release 全量 CTest **346/346** 通过。方向专项 Release **16/16** 通过，包括角度／速度闭环四种标志组合、LK／HT04 开环方向、LK／HT04 电流外环及非法方向值。
- ARM GCC 固件构建：bench_safe、rcdiag、robot-single、robot-chassis、robot-gimbal，各 Debug 与 RelWithDebInfo 两种，共 **10/10** 构建通过。
- `check_firmware_profile.py` 对上述十个 ELF 逐一核对配置角色、链接模块及所选源码，**10/10** 通过。
- CMake 固件使用工程锁定的 ARM 工具链、Cortex-M7 浮点 ABI 和严格格式告警；本轮没有启用 fast-math。主机及固件均未运行电机设备。
- 本机回归证明控制参考符号、输出编码和默认方向兼容性；实际接线方向、设备极性、物理旋向及控制性能仍需后续安全台架验证，不能由这些测试推出。
