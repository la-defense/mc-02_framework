# MC02-0064 与 PARAM-03：参数组事务和旧配置审计

本文记录 BMI088 持久化参数组的实现边界，以及旧 CAN／底盘配置段的审计结果。软件验收只使用 WSL 主机测试和 ARM 固件构建，不连接开发板、不擦写真实 Flash；车型机械值待 APP-10 实物确认。

## 参数目录和生效规则

`bsp_param` 的固定描述目录当前只收录实际由参数模块保存并由 BMI088 使用的字段：

| Key | 类型／长度 | 单位和范围 | 默认／生效方式 |
|---|---|---|---|
| `0x0100` `PARAM_KEY_IMU_GYRO_OFFSET` | `float[3]`／12B | x/y/z，`rad/s`，每轴 `[-0.1, 0.1]` | 每轴 `0`；BMI088 初始化时读取，在线标定成功后更新实例 |
| `0x0101` `PARAM_KEY_IMU_G_NORM` | `float`／4B | `m/s²`，`[9.0, 10.5]` | `9.805`；BMI088 加速度标定使用 |
| `0x0102` `PARAM_KEY_IMU_CALIB_META` | 固定结构／12B，可选 | 成功标志必须为 `PARAM_IMU_CALIB_OK`；摄氏温度 `(-40, 100)`；上电秒数不限 | 仅显示，不参与控制计算 |
| `0x0103` `PARAM_KEY_IMU_CALIB_SCHEMA_VERSION` | `uint32_t`／4B | 当前逻辑版本为2 | 存储识别，不参与运行计算 |

数值范围沿用 BMI088 原有标定合理性检查；它们约束传感器校准输入，不是底盘机械参数或精度保证。Flash 容器头的 `PARAM_VERSION=1` 保持不变，逻辑组版本独立记录在 `0x0103`。

## 事务和旧 A/B 记录

- `ParamImuCalibrationStage()` 检查完整候选组并复制到调用者事务；失败不改事务。
- `ParamImuCalibrationAccept()` 在候选 TLV 缓冲内更新零偏、重力模长、元数据和逻辑版本，完整通过容量及语义检查后才整体替换 RAM。失败保留旧 RAM 组和调用者事务。
- Accept 只代表本次运行已接受／生效，不代表已写入 Flash。BMI088 随后调用 `ParamCommit()`；只有写入、回读和维护回调完成，掉电后才可使用新记录。
- 没有 `0x0103` 的旧 A/B 记录按逻辑 v1 读取。必需核心字段仍须齐全、长度正确且数值有效。旧元数据缺失或无效时丢弃该元数据，但保留有效核心标定值。
- 启动先按序号尝试较新的 CRC 有效记录；其参数组语义无效或版本不支持时再试另一记录。提交仍写非活动区；提交失败不切换活动区和序号，活动记录保留。
- 未描述的旧 TLV 项按原始字节保留。原始 `ParamSet()` 不允许绕过 BMI088 组 API 单独修改 `0x0100`～`0x0103`，并在替换扩容失败时保留旧项。

## 旧 CAN／底盘参数段审计（PARAM-03 部分完成）

| 范围 | 当前持久化目录／调用 | 处理决定 |
|---|---|---|
| `0x0200`～`0x02FF` CAN | 无 `PARAM_KEY_*` 定义，无参数读写调用 | 继续保留为空，不把 CAN ID、总线句柄或设备映射写入 Flash；这些值受车型拓扑和驱动配置约束，尚无确认后的统一来源及范围 |
| `0x0300`～`0x03FF` 底盘 | 无 `PARAM_KEY_*` 定义，无参数读写调用 | 继续保留为空，不新增持久化机械值；缺少实车确认的单位值、范围及交叉约束 |
| `0x0400` 及以上配置描述段 | 无活动描述项或参数读写调用 | 保留规划区，不为扩充目录而创建未使用参数 |

旧运行配置仍分散在编译期宏、配置结构和初始化代码，不能当作已持久化参数。代码核对发现：

- `application/robot_def.h` 中被 `ChassisTask` 直接用于运动计算的几何宏为轴距 `350 mm`、轮距 `300 mm`、轮半径 `60 mm`、减速比 `19`。
- `application/config/sentinel_robot/sentinel_config.c` 里的移入配置对象另列轴距 `500 mm`、轮距 `500 mm`、轮半径 `150 mm`、减速比 `19`，文件注释标明沿用历史配置并需按实车核对；当前 `ChassisTask` 并未用该对象提供运动几何。
- `ChassisInit()` 直接登记四个底盘 DJI 电机 ID `1、2、4、3`；哨兵配置对象则按 `LF=3、RF=2、RB=1、LB=4` 保存 ID 映射。不得把一方复制为持久化默认值。
- 旧配置还列有电机 PID、CAN 句柄和电容／其他设备 ID；这些都是当前代码配置数据，不是 `bsp_param` 的旧 Flash 参数键。本轮未改变控制公式、ID或 PID。

因此 PARAM-03 的“旧分段是否曾有有效 Flash 字段”结论是：当前仓库无相关 key、无载入／保存调用；CAN 与底盘配置只保留在运行代码中，Flash 区段维持预留。统一配置接入和机械值选择需等 APP-10 确认真实轴距、轮距、轮径、安装角、减速比、云台偏置与限位；PARAM-03 在这项信息确认前继续开放。

## 本机验证记录

`tests/host/param_operation_test.c` 通过生产参数代码和模拟 Flash 覆盖目录、事务失败、未初始化、旧逻辑 v1 读取、语义无效的新记录回退、容量不足和 Flash 写入失败。BMI088 生产测试使用参数组替身检查完整标定路径调用 Stage／Accept；不会对实板擦写。

最终验收记录：

- WSL Debug 和 Release 主机全量测试各 `395/395` 通过；新增参数组测试在 Release 下继续生效，场景由 CTest 限制在10秒内。
- 参数组事务、BMI088 标定迁移和数值回归的 ASan／UBSan 子集 `10/10` 通过。
- `bench_safe`、`rcdiag`、`robot single/chassis/gimbal` 的 Debug／RelWithDebInfo 共10种 ARM 固件构建通过。
- `arm-none-eabi-size` 与构建链接区报告显示各配置 `.bss` 增加512字节（候选 TLV 工作区），`.data` 不变；文本增加约1.3～1.8KiB，仍在 Flash 分区内。没有新增堆分配。
- 未连接开发板，未擦写真实 Flash；测试 Flash 均为主机映射模拟区。
- 扩大到全部 BMI088 初始化故障 ASan 用例时，`bmi088_init_spi_failures_abort_attempt` 因测试循环没有释放每次成功返回的长期实例而报告8个泄漏；该测试夹具的清理不属于本参数组迁移范围。参数组与标定迁移的定向 ASan／UBSan 子集通过。
- 本地提交 SHA 由本轮交付记录提供。

MC02-0064 软件验收完成。PARAM-03 的目录审计已记录，但实车几何与唯一配置来源仍需 APP-10 提供数据，因此 PARAM-03 保持开放。
