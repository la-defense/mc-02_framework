# MC02-0070＋MC02-0089：固定话题中心与版本化视觉业务协议

任务状态只在[TODO](../../../.Doc/TODO.md)维护。本轮使用`feat/message-topics-v2-protocol`，基线`db889f8`。验收仅使用WSL主机和ARM交叉构建；没有连接或烧录开发板，也没有运行Windows原生构建。

## 消息中心

[MessageCenter](../../../modules/message_center/message_center.h)采用启动期固定目录，检查话题编号、负载长度、最大年龄、快照／事件类型、容量、溢出方式、时钟域及发布／订阅端点。初始化复制目录；运行期发布只复制数据和三种时间，不申请内存。不同任务并发读写由短临界区保护。

`MessageFreshness_t`分别记录来源时刻、首次本机接收时刻和本次发布时刻。远端原始时钟只保存；未完成映射时不与本机时钟相减，过期判断按首次接收时刻。快照读取不消费、不续期；事件FIFO按顺序丢弃过期队头，不越过旧事件执行后续事件。拒绝新事件或覆盖旧事件由话题目录固定选择。

全局订阅数据区为2048字节。独立进程测试用8个`64字节×4槽`订阅恰好用满，验证第9个订阅失败且重复注册不再占空间。主机线程测试交错发布与读取200,000条带互校验字段的数据，未观察到混合快照。已配置事件队列测试覆盖满队拒绝、旧项覆盖、队头过期和全部过期返回`MESSAGE_ERR_EXPIRED`。

目前单板应用目录配置8个连续快照话题，包括底盘／云台／发射命令与反馈、瞄准、导航和姿态。V2没有操作或开火字段，所以本轮不虚构业务操作事件；事件FIFO由独立目录测试覆盖，后续具体操作类型仍须由业务协议定义。独立队列余量／统计导出和调试端口仍归MC02-0012；跨板桥接和对时仍归MC02-0092／0093。

## V2协议与控制行为

构建配置`MC02_VISION_PROTOCOL=sp|v2`，默认SP。V2当前只允许`robot/single`；`bench_safe`、`robot/chassis`、`robot/gimbal`及未知协议的CMake配置均被拒绝。编译数据库、选择源码清单和ELF符号确认：SP固件包含`vision_protocol.c`及SP流解析符号，V2固件包含`vision_protocol_v2.c`及V2符号，不再把未选解析器编入最终映像。

帧格式为12字节`MC`／版本／类型／长度LE16／序号LE16／来源时刻LE32头、固定负载和2字节CRC16_MODBUS_A5。负载长度：瞄准25、导航13、姿态34、裁判摘要36字节。二进制32位浮点明确按小端IEEE-754读写，拒绝NaN／Inf；非法输出不改写原对象。主机测试使用独立核对的完整帧向量，不以生产编码后自解码作为唯一依据。

瞄准字段采用rad、rad/s、rad/s²；导航按机器人本体坐标x前、y左，以m/s和rad/s表达。转换至现有底盘mm/s及deg/s时检查非有限值和可用范围。进入自主移动同时要求遥控器在线、左开关选择自主、PC有效、RobotSafety为READY、裁判机器人状态及功率热量组新鲜，且裁判底盘供电位有效。瞄准和导航分别按50ms和100ms接收年龄到期；瞄准失效禁用瞄准和视觉击发，导航在许可齐备时仍可单独移动。导航或许可失效、整条USB业务链路离线时发布零移动。V2没有视觉击发字段。

USB代际变化后首个合法新帧可从任意序号开始，并在提交前清除上一代的瞄准和导航快照，避免另一类尚未到期的旧命令被重用。远端来源时间保留在元数据中，不要求控制恢复前先完成对时或会话握手。姿态和裁判摘要由MCU交替回传，三组裁判数据各自提供有效位和接收源时刻。

## 验证结果

- WSL Debug和Release全量CTest各`359/359`通过。Release测试使用持续生效的`TEST_CHECK`；新增测试设置10秒超时。
- V2专项ASan／UBSan测试`6/6`通过，包含固定向量、生产MasterProcess接收／CRC／话题、控制任务、消息新鲜度、2048字节容量和真实线程交错。
- 固定向量检查四类负载和完整帧字节；协议测试覆盖每个拆分位置、多帧、噪声、CRC／版本／长度／值错误、丢块、代际变化和组帧超时。旧快照不因新连接另一业务类型的帧而被复用。
- `MC02_VISION_PROTOCOL=v2`与`bench_safe`、双板角色的非法组合及未知协议均在CMake阶段明确拒绝。协议源切换使已有SP和V2构建目录自动重新生成；V2曾暴露无条件调用SP清理函数的链接依赖，修正为按协议编译后，SP、V2 ELF分别只保留对应解析器符号。
- WSL工具链使用ARM GNU 10.3.1，实际`-mcpu=cortex-m7 -mfpu=fpv5-d16 -mfloat-abi=hard -fno-fast-math`。Configure时格式诊断的16组正反例通过。
