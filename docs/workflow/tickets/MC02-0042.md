# MC02-0042：BMI088 启动失败导致看门狗复位

本文件记录验收细节；任务状态只由 [.Doc/TODO.md](../../../.Doc/TODO.md) 管理。

## 发现

bench_safe 固件通过 OpenOCD 写入和校验后，板子在启动约 1 至 2 秒时发生 IWDG 复位。被控停核诊断观察到 `INS_Init()` 的 `bmi088_ins == NULL` 分支进入无限循环；复位标志表明随后由 IWDG 重启。BMI088 驱动在多个重试后返回空指针，而 INS 任务没有提供传感器不可用时的降级路径。

BMI088 初始化分支原本只在 RTT/日志中报告重试错误；当前 COM14 读取工具遇到 `ClearCommError`，需要增加可从 SWD 读取的诊断字段，明确最后错误、HAL 状态及芯片 ID。

## 实施要求

- 将 INS 初始化等待统一走任务监控的协作延时：调度器运行时每次等待最多一个 RTOS tick，并刷新所属任务心跳；调度器未运行时用 DWT 延时。
- BMI088 初始化失败后保持加热关闭、上报 IMU 与标定无效，并让 INS 任务继续以新鲜任务心跳运行。无效传感器样本必须沿既有视觉清零路径发送零控制状态。
- 暴露最后一次 BMI088 初始化错误码、加速度计／陀螺仪 HAL 读状态、芯片 ID 和重试计数，供有界只读调试使用。
- 不在故障分支喂 IWDG；只有正常任务监控在各任务健康时才喂狗。

## 验收

- 主机测试覆盖任务监控延时在调度器运行／未运行两种路径，以及 BMI088 错误初始化诊断。
- host CTest Debug、Release 全部通过；bench_safe Debug、RelWithDebInfo 固件构建成功。
- 裸板 USB 供电运行 10 分钟，任务监控计数持续增长，IWDG 复位标志不增加；加热 PWM 与执行器输出保持关闭。
- 如果 BMI088 初始化仍失败，记录返回的错误码、SPI 状态及芯片 ID；这时只验收安全降级和通信存活，不得宣称自瞄验收通过。

## 2026-10-07 USB 裸板烧录回归

测试边界：仅开发板、LCD、USB 和 CMSIS-DAP；未接 TB47S、电机、舵机或其他执行器。下行仅发送 `mode=0`、浮点字段全零的中性命令帧，没有发送非中性控制帧；不使用 halt/reset 快照命令。固件产物为 `bench_safe`，SHA-256：`a2209b65cdb929904194a90d78e80039bd2c8745f07be0f0b1fae5b265f3912b`。

- Windows OpenOCD 0.12 通过 CMSIS-DAPv2 探针（Horco v0.2，DPIDR `0x6ba02477`）烧录并回读校验，日志包含 `Verified OK` 和 `Resetting Target`。烧录前 1 MiB 备份为 `build/flash-tools/mc02-before-reflash-20261007.bin`，SHA-256：`da198d7abdaaa7f60f8eb292df7f29e8e119287f6a181c461f8df78b7c8b20ae`；参数区备份 SHA-256：`413f4da1afa9483a6bf156cb7124f05276927eb843ce5d040c85725257120de4`。
- 烧录后被动 SWD 运行观察 10 分钟，共 60 个 10 秒采样点。`monitor_tick_count` 从 `0x2f7f` 连续增长至 `0x1166d`，每个样本都递增；60/60 样本的 IWDG 复位标志均为 `0`。日志：`build/flash-tools/mc02-0042-stability-10min.log`。OpenOCD 完成最后一次读取并执行 `shutdown`；进程退出码为 1，但日志有完整 60 个样本且没有读取错误。
- 只读寄存器快照：加热占空比 `0`、TIM3 CCR4 `0`、CCER `0`、CR1 CEN 位为 `0`，PB1 输出锁存为低；GPIOC 的 PC13/14/15（可控电源输出）均为低。软件状态 `IMU_VALID=0`、`CALIB_VALID=0`、BMI088 指针为空，IWDG 标志为 `0`。该结果是 MCU 软件状态与寄存器验证，不代表测量了 PB1 实际波形或外部电源轨电压。
- COM14 被动抓取 5 秒得到 43,645 字节；找到 1,015 个完整 43 字节 `SP` 状态帧，按工程 CRC16（初值 `0xFFFF`、反射多项式 `0x8408`、低字节在前）校验全部通过，坏 CRC 候选为 `0`，约 `203 Hz`。对保存数据逐帧解码发现 1,015 帧均为 `mode=0`、四元数及 yaw/pitch 控制字段为零、`bullet_count=0`；`bullet_speed=30` 是状态元数据默认值，不是发射命令。抓取文件：`build/flash-tools/mc02-0042-com14-5s.bin`。
- 按裸板回归发送 1,000 个 29 字节中性命令（`mode=0`，6 个浮点字段均为 `0`，无瞄准/开火内容），COM14 写入 `29,000` 字节。发送前 SWD 读取 RX/CRC 计数均为 `0`；发送后 RX=`1,000`、CRC=`0`，IWDG=`0`。停发超过 50 ms 后，被动读取发现接收帧前缀及 `last_rx_ms` 均归零，证明离线回调已撤销旧命令。命令帧：`build/flash-tools/mc02-0042-neutral-frame.bin`；SWD 日志：`build/flash-tools/mc02-0042-neutral-before.log`、`build/flash-tools/mc02-0042-neutral-after.log`。
- 传感器故障诊断保持 `BMI088_NO_SENSOR (0xff)`、重试 5 次、加速度计 ID `0x00`、陀螺仪 ID `0x0f`；SPI HAL 状态均为 `HAL_OK`。因此本次验收的是初始化失败后的安全降级、任务监控/看门狗持续运行、状态帧输出及中性视觉命令的接收；**没有验收 IMU 初始化成功、非中性视觉命令或自瞄**。
