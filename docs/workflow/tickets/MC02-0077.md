## 实现与使用条件

- 在既有 [sample_filter.h](../../../modules/algorithm/sample_filter.h)／[sample_filter.c](../../../modules/algorithm/sample_filter.c) 中增加统一的初始化、重置、更新和查询入口，支持一阶低通、固定样本数平均、Butterworth 二阶低通和陷波。
- 调用者长期保存清零后的固定地址实例；平均另提供独占历史数组，窗口为 1～255。配置整体检查通过才接受；重配失败保留旧实例和历史。运行不使用硬件时钟、动态分配或共享历史。
- 更新显式传入样本存在标记和实测秒间隔，运行中 dt 边界允许。首次采样及异常后的下一份有限样本忽略该次 dt，建立常值历史并返回 `FILTER_REBUILT`；输出等于当前输入。
- 缺样、非有限输入、dt 异常或计算溢出撤销有效标记并等待重建，保留最后数值、历史和计数。参数错误保留整个实例；任何未交付新结果的返回均保留输出参数。查询只复制诊断值，不能延长来源有效期。
- 一阶系数为 `dt/(tau+dt)`。二阶使用梯形积分的两状态形式，`g=tan(π*f*dt)`；低通 `k=√2`，陷波 `k=1/Q`。频率须满足 `f*dt_max<0.5`，配置两端的 double 系数还须通过有限及严格稳定性检查；更新继续检查本次系数和候选值。
- 原 `MovingAverageF32()`、HT04 五点平均和零填充启动行为保持原规则。现有 CMake 和 Makefile 已收录此源码，不另建重复清单；实际电机／姿态滤波参数没有改动，接入工作仍由 MC02-0017 跟踪。

计算依据为 Andrew Simper 的 [Linear Trapezoidal Optimised SVF](https://cytomic.com/files/dsp/SvfLinearTrapOptimised2.pdf)，采用其中状态方程自行实现；[作者技术资料页](https://cytomic.com/technical-papers/)说明该知识可自由使用。2026-10-19 核对的 PDF 为 697239 字节、SHA256 `0d4da92b5ece888125c7562c3ae542dfa5155f1b6e781db5da2b2ad20aa02779`，文档更新日期为 2016-11-20。原有源码作者说明保留。

## 数值与故障验证

[生产接口测试](../../../tests/host/sample_filter_test.c) 使用始终生效的检查，四个 CTest 用例各设 15 秒超时。

| 检查 | 数据及判定 |
| --- | --- |
| 时域参考 | 四种类型分别运行固定、交替和随机 dt，各 30000 次；交替为 0.5／1.5 ms，随机在允许范围内。典型参数为 tau=10 ms、fc=20 Hz、Q=4、平均9点。绝对加相对容差均为 `3e-6`。 |
| 独立参考 | 一阶使用加权公式并核对阶跃闭式解；平均直接求和；二阶由 double 二元梯形方程消元求解，避免复写生产优化公式。 |
| 频响 | 1／5／20／40／100／200 Hz 正弦，fs=1000 Hz，先稳定8秒再相关测量2秒；实部、虚部与独立复数传递函数差均不超过 `2e-5`。二阶20 Hz增益约 `1/√2`，陷波中心增益小于 `1e-4`。 |
| 生命周期与异常 | 首次、缺样、NaN／Inf、dt上下界内外、重建、重置、查询、真实溢出；失败保留旧输出和数值历史，无部分提交。 |
| 存储与参数 | 空参数、非法配置、极端系数、容量不足、错位、地址范围溢出、重叠、复制实例、窗口1／255及尾部哨兵。失败初始化不改变原对象和历史。 |
| 实例独立 | 四种实例各交错10000次；Linux另用四线程各运行10000次，与独立参考核对。同实例仍要求串行访问。 |
| 分配器与兼容 | Linux链接包装检查初始化／更新无分配器调用；线程运行时自身分配不列入该检查。既有数值和HT04测试继续运行真实计算函数。 |

长序列有限和数值一致的结论仅限这些已测参数与输入范围，不作为任意配置、硬件耗时或实际姿态精度保证。
