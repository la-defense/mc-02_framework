## 三角函数接口

INS 和底盘坐标转换通过 `fast_trig.h` 调用正弦、余弦，接口只使用 C 的 `float`。当前实现 `fast_trig_cmsis.c` 继续调用固定的 CMSIS-DSP 1.7.0，弧度输入、查表结果和现有计算顺序保持一致；不申请内存或保存跨调用状态。调用者须提供有限角度并满足接口写明的缩放范围，接口不替代输入检查。

`dsp_numeric_test` 以 -8π～8π 内 16385 个角度分别对照双精度正弦／余弦，误差限为 3e-5。WSL Debug／Release 中该测试各 1/1、两种 INS 后端相关用例各 16/16、底盘相关用例各 10/10 通过；底盘测试现使用实际 CMSIS-DSP 后端。完整套件和其余平台接口仍需后续验证。

同为 WSL ARM GCC 10.3.1 的禁热 `bench_safe` Debug 构建，基线 FLASH 242604 B、RAM 116720 B；本次 FLASH 242620 B、RAM 116720 B，分别增加 16 B 和 0 B。生成的 ELF 确认 VFP 寄存器传参，`FastTrigSinF32` 调用 `arm_sin_f32`；这增加一次函数调用，不代表板上耗时或实时上界已经测量。源码清单／ELF 角色检查和 CMSIS-DSP 来源指纹检查通过；未连接开发板。

## 矩阵接口

`dsp_matrix.h` 定义框架自己的矩阵描述符和计算状态，KF、QuaternionEKF 与 RLS 不再引用 CMSIS 矩阵类型。后端逐次将描述符转换为 CMSIS 格式，实际计算仍调用同源 CMSIS-DSP；求逆仍使用独立工作区，成功后才提交输出。转换增加调用与局部描述符，实际耗时和栈峰值尚未测量。

只提供算法目录头路径的独立编译目标通过。WSL Debug／Release 下矩阵与三角函数、KF 结果与失败注入、RLS 四项及 INS 十六项回归均通过；ASan／UBSan 下数值、KF 与 RLS 共六项通过。ARM 禁热 Debug 固件 FLASH 为 243044 B、RAM 为 116720 B，相比原基线分别增加 440 B 和 0 B；源码清单与 DSP 来源检查通过，ELF 保留硬浮点 ABI，矩阵适配器调用 `arm_mat_mult_f32`，其中可见浮点乘法指令。ELF SHA-256：`713a3b7e209a0a30adcdf0918933dc40526a69a94b4c7417340ddb420bb202cc`。这些结果不代表实板性能或完整任务验收。

DSP CMake 目标只向调用者提供框架接口目录，CMSIS 头目录及主机可移植宏改为私有；需要包装 CMSIS 函数做故障注入的 KF／RLS 测试单独声明后端依赖。调整后 Debug 专项回归和禁热 ARM 构建及源码清单检查通过；其他业务目标的 HAL／RTOS 头路径仍未隔离。

MC-02 数值能力接口分别报告 H723 的 FPU、DSP 指令、CORDIC 和 FMAC 硬件，以及当前编译目标选择的 CMSIS 后端和编译器允许的浮点／DSP／硬浮点 ABI。硬件存在不代表外设已启用；CORDIC／FMAC 仍无生产后端。当前接口没有消费者，链接器可从固件中移除未使用的查询函数。ARM 编译器宏确认 `__ARM_FP=14`、`__ARM_FEATURE_DSP=1`、`__ARM_PCS_VFP=1`；主机数值能力查询测试与禁热 ARM 构建通过，Debug／Release 全量各 499／499，专项 ASan／UBSan 通过。未测硬件性能。

## 任务创建与等待的首个接入

Daemon 独立事件任务改用框架的 `PlatformTaskCreate` 和 `PlatformTaskDelayMs`；FreeRTOS 后端将配置映射到现用 CMSIS 接口，保留原来的 512 栈字、低于普通任务的优先级及 1 ms 等待。任务可能在创建返回之前运行，Daemon 仍在调用前开放消费者编号，创建失败时撤销并上报。后端拒绝空配置、无效优先级和不能装入当前 16 位栈深类型的大小。该接口尚未涵盖通知、时间和临界区，也未迁移其他任务。

使用生产后端配合 CMSIS 主机替身，Debug／Release／ASan＋UBSan 的 Daemon 八项测试各通过；包含非法任务配置、创建失败重试、事件及并发场景。禁热 ARM Debug 编译及源码清单检查通过，FLASH 243180 B、RAM 116720 B；未连接开发板，未验证板上调度时限。

## 消息中心同步与计时

消息中心改用 `platform_sync.h` 的任务临界区和毫秒计数；H723／FreeRTOS 后端分别调用原有任务临界区宏和 `HAL_GetTick`。接口允许在调度器启动前或任务上下文配对使用，不能从中断调用；它不替代其他模块保存并恢复中断屏蔽状态的路径。消息中心可只使用框架头独立编译，主机测试中的后端仍分别使用对应测试的时钟及临界区替身。

专项测试验证两层任务临界区配对、毫秒计数回绕、消息新鲜度及跨线程读取一致性。Debug 全量回归 497／497、Release 相应测试及 ASan／UBSan 同步／消息测试通过；禁热 ARM Debug 固件和源码清单检查通过。全量检查发现独立编译目标缺少格式诊断参数，已让对象库与其他目标一并使用该检查。其他业务中直接使用 HAL／RTOS 的调用仍需迁移，本步骤未验证板上执行耗时。

Daemon 来源监控也已使用相同接口，来源原始时间、超时判断及事件派发顺序保持原样；生产文件只凭框架头可独立编译。每个主机目标仍使用其原来的锁和时钟替身。WSL Debug／Release 全量各 497／497，ASan／UBSan 的 Daemon 八项和遥控并发一项通过；禁热 ARM Debug 构建与源码清单检查通过，FLASH 243204 B、RAM 116720 B。未测实板耗时。

## 中断屏蔽状态

`platform_irq.h` 单独提供保存并屏蔽、恢复原状态的接口，STM32 后端仍使用 PRIMASK。车型故障标记先保存状态，更新故障结果后恢复，不会在调用前已经屏蔽时擅自打开中断。主机测试通过生产车型入口覆盖嵌套、原先已屏蔽、辅助失败和核心失败；Debug／Release 全量各 498／498，专项 ASan／UBSan 通过。禁热 ARM Debug 构建和源码清单检查通过，FLASH 243220 B、RAM 116720 B。其他中断屏蔽调用、板级资源及运行耗时仍待处理。

遥控输入对中断屏蔽和毫秒计数的直接调用也已改用框架接口；串口设备类型和接入仍沿用现有实现。Debug／Release／ASan＋UBSan 下遥控相关 13 项及 PC 过期与接管测试均通过，测试目标仍使用原有的线程锁和计时替身。实际包含遥控模块的禁热 `rcdiag` ARM Debug 固件及源码清单检查通过，FLASH 245988 B、RAM 117080 B；未连接硬件。

## 双板桥接的逻辑 CAN 编号

车型的双板桥接配置使用 `PlatformCanBus_t`，不再保存 STM32 句柄；MC-02 板级绑定将逻辑总线 1／2／3 分别映射到当前 FDCAN1／2／3。底盘板和云台板仍分别选择原来的第二和第一条总线，帧 ID 和话题保持原值。桥接启动在注册任何话题或设备前拒绝未声明的编号；有绑定不等于总线已启动或设备在线。

生产桥接与板级映射在两种角色的主机测试中检查三条映射、非法编号、注册及既有对时链路；Debug／Release 全量各 498／498，ASan／UBSan 双角色 2／2 通过。禁热 `bench_safe` ARM 固件与源码清单检查通过，但该配置不编入双板桥接；生产哨兵尚因既有条件禁止生成，因而不能把主机结果称为双板固件或实物通信验收。桥接实现仍依赖 STM32 类型，需要继续迁移。

## 电机配置的逻辑 CAN 端点

`Motor_Init_Config_s` 的 CAN 配置改为逻辑总线及收发 ID，电机公共配置头不再包含 CAN／HAL 头；车型不再保存四类电机的硬件句柄。DJI、LK、HT、DM 驱动注册前调用板级适配把端点转换为现有 CAN 注册结构，无效绑定在分配或注册前拒绝。底盘和发射的节点冲突检查比较逻辑总线，保留原来的 ID、总线分组及控制行为；未启用的 XM 骨架和超级电容仍不在本次接入范围。

电机公共配置头在没有厂商／RTOS 头路径的目标中编译通过。Debug／Release 全量各 499／499；新增无效总线拒绝、失败不改旧端点及底盘核心配置检查在两种构建下通过。ASan／UBSan 覆盖四类电机注册、故障及双板桥接；四种驱动、底盘、云台、发射和双板桥接源文件按当前 ARM 编译选项独立编译通过。这些独立对象不构成机器人固件，也未驱动硬件。禁热遥控诊断固件构建通过；生产机器人仍受已有参数与功能门槛限制。

## 可移植框架对象目标

来源监控、其事件任务和消息中心从固件主目标拆入 `mc02_portable_framework` 对象目标；只提供来源、消息、框架 OS 和格式检查所需头路径，仍直接链接进相同固件。源码检查验证编译数据库中每个文件恰好出现一次、头路径属于允许范围、Ninja 实际头依赖不引入其他工程目录，并检查最终链接命令实际包含相应对象。测试覆盖非法厂商／RTOS 路径、强制包含、实际依赖和只编译未链接的情况。

禁热 `bench_safe` 和 `rcdiag` ARM Debug 构建及源码检查通过；WSL Debug／Release 全量各 500／500。同一 ARM GCC 10.3.1、Debug 选项、`e69c0eb` 源码基线下，`bench_safe` FLASH 242604→243164 B、RAM 116720→116736 B。使用编译器 `-fstack-usage` 比较相应单函数栈：Daemon 最大值 336→336 B，事件任务最大值 64→56 B，消息中心最大值 80→80 B；新增 `PlatformTaskCreate` 为 40 B，任务临界区和毫秒计时适配函数各为 8 B，中断屏蔽适配函数各为 0 B。这些值不包含完整调用链或中断嵌套，不能当作实板栈峰值。
