# MC02-0084：RGB 与蜂鸣器接入统一 safety 告警

任务状态只在[TODO](../../../.Doc/TODO.md)维护。本轮共用分支 `feat/safety-alarm-rgb-buzzer`，基线 `fbb0b58`。验收限定为 WSL 主机测试与 ARM 固件构建；未连接或烧录开发板。

## 实现范围

- 新增纯策略层与运行适配层。策略每轮读取一致的 `RobotSafetySnapshot_t`，按配置优先级持续选取最高优先级故障；故障解除后选取下一项，无故障时显示 STOP、INIT、SAFE、CALIB、READY、FAULT 或 ESTOP 状态。未知故障位和未知状态有各自的配置后备样式。
- 车型表显式配置9种已知故障、7种状态、灯光及声音节奏、静音等级和期限。分段数量最多8，单轮节奏不超过10秒；灯段可循环或播放一次后保持末段，灯与声音共用事件起点，各自按同一实际毫秒时钟推进。相邻推进间隔小于一个完整32位计数周期时，累计时长跨多个周期继续推进节奏。静音请求从任务接口排入单槽，由后续任务轮次处理，只影响允许等级的蜂鸣器，不修改许可、故障和灯光。
- `RobotInit()` 在 safety 初始化后选择车型配置并初始化告警。LED／蜂鸣器初始化及运行失败只让对应辅助通道降级，不报告核心初始化失败，不改变关热、许可或看门狗路径。Daemon 每10毫秒调用告警入口；策略只在所需输出变化时提交驱动请求。
- 蜂鸣器使用类型化接口和固定频率表，`OCTAVE_8` 映射1046Hz。WS2812 驱动返回 HAL 状态，单次发送124字节并使用2ms HAL 超时参数；发送前申请时基 lease，时基不可用时拒绝发送。调度影响实际耗时；当前发送仍为阻塞调用，未满足本任务的异步输出条件，SPI／灯珠实际波形和板上时序仍由 **MC02-0025** 跟踪。

## 本机验证

- WSL `host-debug`、`host-release` 全量主机测试各 **434/434** 通过。
- ASan／UBSan 告警与 WS2812 专项回归 **15/15** 通过，覆盖故障与急停同时存在、仲裁优先级、分段循环／单次保持、完整计数周期后的节奏、静音验证与状态代际、配置拒绝、输出失效、无效 safety 快照、音符映射及 SPI 引脚／数据编码。
- ARM GCC 10.3.1 禁热固件的 bench_safe、rcdiag、robot single／chassis／gimbal 各 Debug 与 RelWithDebInfo 十种预设均构建成功。每次配置的格式检查为16个编译正反例；无 fast-math，浮点 ABI 沿用工程 Cortex-M7／`fpv5-d16`／hard-float 设置。构建产物位于忽略目录 `build/wsl/`。
- CMake 增量检查覆盖未登记源码排除、源码登记／移除／移动、头目录迁移与历史模板排除，均与干净配置一致。记录位于 `build/wsl/robot-alarm-regeneration/run-20261027-205252-g3rm3ih1/`。该检查在加入时基 lease 之前完成；此次后续修改没有改变固件源码清单。
