# R25-02：视觉接管范围与撤销保护

基线 `4149c1e`，沿用 `fix/mc02-0045-bmi088-init`。任务状态只在 [.Doc/TODO.md](../../../.Doc/TODO.md)；本轮软件与裸板回归不替代真实机械范围和执行器失能验收。关联 R25-06（命令来源）、R25-08（实机限位）、R25-13（CI）。

## 接口与配置

生产 `vision_control` 增加 `VisionControlLimits_s`、`VisionYawConstraint_e` 与 `VisionControlGimbalCommand_s`；`VisionControlInput_s` 引用限位配置，新增 `VisionControlBuildGimbalCommand()`。配置使用最终云台命令坐标系的度，输入和 SP 帧仍使用弧度。

配置未就绪、缺失、包含非有限值或俯仰上下限不递增时拒绝接管。偏航必须明确为连续旋转或有限范围；有限偏航要求上下限递增，连续偏航不限制角度圈数，保留输入的多圈值，但配置值仍须有限。`robot_def.h` 默认 `VISION_LIMITS_CONFIGURED=0`，不写入任何模拟机械参数；仅主机模拟目标通过编译定义使用俯仰 [-20°,30°]、零偏 5°、偏航 [-180°,180°]。

可用输入必须在线、mode 1/2、年龄不超过调用方门槛且门槛不大于 50ms，六个输入和转换输出均有限。俯仰在转换并加零偏之后检查，边界允许、越界拒绝，不钳位。云台构造失败输出全部清零；发射使用相同可用性判断。43/29 字节 SP 帧、CRC、参数 A/B 存储格式均不变。

## 每周期命令生成

`RobotCMDTask()` 只读取一次视觉帧/状态组合快照，建立一份含时间与不可变配置引用的输入。手动映射不再访问或重复应用视觉输入。遥控链路在线且左侧开关选择遥控/键鼠时，才认为手动来源有效；RobotSafety 仍在发布前做最终失能覆盖。

每周期先清除四个视觉前馈。首次进入手动或视觉撤销后切回手动时，必须在本周期取得云台反馈且 YawTotalAngle/Pitch 有限；以该姿态为起点应用当前手动增量，未取得反馈则云台、发射和底盘中立，并保持等待新反馈。正常连续手动控制保持角度增量累积，不将每周期目标重置到反馈。SAFE 等状态会清除手动参考就绪状态，避免重新使能后继承失能前的目标。

无有效来源时，完整清零云台目标与前馈并设 ZERO_FORCE，关闭射手与摩擦轮、停止装填、射频归零；底盘进入 ZERO_FORCE。视觉 mode 2→1 保留视觉预热但停装填，mode 0/失联/过期/越界回到当前有效手动命令；没有手动来源则中立。遥控离线时不处理旧组合键使能/清急停。

## 裸板回归与后续边界

软件验证、教学文档和提交后重新确认裸板与限流供电，备份 1MiB Flash 和参数区，检查 ELF 加载范围，直接 OpenOCD 正斜杠路径烧录 bench_safe Debug 并 verify，核对擦除范围与参数逐字节保留。60 秒中检查运行态、IMU 有效性、禁热与固定寄存器隔离；COM14 单客户端准确发送 1000 个 mode=0 全零中性帧，检查 RX/CRC、停发后旧帧及时间清零，并被动校验状态帧。mode 2 只在主机模拟中使用。

裸板不运行整机 robot_cmd；本轮板上结果只能证明启动、通信和隔离。全部通过后 R25-02 仍保留真实机械参数与台架输出失能验收；用户明确选择有效手动接续，因此“视觉失效”撤销视觉控制，不会禁止仍有效的手动发射请求。完整测量及物理失能结论仍需相关台架条件。

连接、烧录、校验或读取失败保存证据并停止，不自动重试、不将只读检查转为停核/复位。教学见[学习笔记 22](../../学习笔记/22-失联安全与有界等待.md)。

### 人工验收发现 LCD 异常

用户报告：启动持续黑屏直到操作按键，翻页有约 0.1–0.2 秒黑场；短按翻页和长按中键都有概率恢复，长按更容易，恢复后一段时间可能乱码或意外翻转。电流曾到约 0.11A，随后回落至约 0.09A、CV 亮。未测量支路电流，不认定电流变化的来源。

因此本轮 **LCD 人工显示验收未通过**，不能称全部裸板验收通过。自动启动、通信及寄存器隔离证据仍成立；显示故障独立由 [MC02-0046](MC02-0046.md) 继续定位。R25-02 还需真实机械范围和台架输出失能验收，未关闭。自动回归结束后的 LCD 复现另执行了一次明确协调的 MCU 复位，不重新烧录；它不是 60 秒自动回归中的非预期复位。
