## 配置与中断基础

哨兵三路受控电源先声明为未确认，生产配置的能力检查拒绝未确认阶段；裸板配置仍允许构建，且板级电源阶段执行器完成之前生产构建继续拒绝。配置测试使用明确的测试阶段，不代表真实负载已确认。WSL 车型选择脚本7项通过；修改前新增的电源检查用例因入口不存在而失败。

共享 EXTI 入口改为分别把10号、12号引脚交给 HAL；当前同步 IMU 采样不启用该中断。UART8／9和I²C2退出时先关闭并清除对应中断，随后沿用原DMA退出步骤。WSL Debug、Release与ASan／UBSan的生产 EXTI 入口模型各1项通过；普通禁热 ARM 固件及实际源码、头依赖和链接检查通过，FLASH 243304 B、RAM 116728 B。IRQ／DMA 的完整失败和重复退出回归仍需补齐；这些结果不证明板上中断、电源或波形行为。

## 早期保护的基础组件

三路受控电源的 GPIO 初始化现在始终先写入关闭电平，再配置输出模式。主机直接编译生产 GPIO 源码，分别用裸板与生产宏检查写入顺序；这只是默认关闭，按配置分阶段开启及依赖检查仍待完成。新增不依赖 HAL 和 RTOS 的有界等待组件，测试固定期限、计数回绕、停止计数、过期就绪及无效参数；它尚未接入 H723 时钟初始化，不能视为硬件时钟等待已受保护。移除活动源码中未使用的 OSPI 示例缓冲；它们先前已被链接器丢弃，因此这一步没有减少 ELF 中的 RAM。

WSL Debug、Release 和 ASan／UBSan 分别通过等待组件 1 项、电源 GPIO 2 项。普通禁热 ARM Debug 构建及 profile 链接检查通过，FLASH 243304 B、RAM 116728 B。未执行完整回归、其余固件组合或硬件测试。

## CAN 接收异常的初步处理

接收 HAL 返回错误时立即退出本轮 FIFO 处理；超过8字节的 DLC 和 FD 帧不再当作零长度经典帧派发，真正的零长度数据帧仍允许。HAL 在返回帧头前会先复制负载，因此目标缓冲按64字节预留；实际业务帧上限仍为8字节。WSL Debug、Release、ASan／UBSan 的异常帧和读取失败用例均通过，Debug 满队列回归通过。ARM 禁热 Debug 构建通过：FLASH 243304 B、RAM 116696 B；新增的中断栈占用尚需在最终验收量化。

这尚未完成扩展 ID、过滤器和共享消息 RAM 改造。当前 HAL 按 DLC 从消息 RAM 读取，目标缓冲扩大不能证明超过硬件配置的8字节时不会读到相邻元素；需要在后续实现中结合控制器配置和异常帧处理解决，并验证消息 RAM 边界。
