# MC02-0082：Fusion 可配置姿态后端

## 范围与来源

从 `9eb0591282a87fd85bf60d93342d67dba73717d2` 建立 `feat/fusion-attitude-backend`。本轮只把 Fusion 接入现有完整 BMI088 样本入口，保留 QuaternionEKF 作为默认后端；不扩展 BMI088 异步驱动、多传感器实例服务、外部姿态源或动态热切换，相关能力仍由 MC02-0005 跟踪。

Fusion 固定到官方提交 `a8d7224f36a0ec82345ef49a3db50e65f8d3bab8`，原始 MIT 许可随源码保存。逐文件校验值及单位来源记录在 [Fusion 来源清单](../../../Middlewares/Third_Party/Fusion/SOURCE.md)。本工程适配层输入陀螺仪 rad/s、加速度 m/s²，转换为上游需要的 deg/s、g，坐标约定使用 NWU。

## 实现

- `AttitudeFilter_t` 和单独工作区由调用者长期持有；QuaternionEKF 新增实例接口，保留旧全局兼容入口。
- CMake 提供 `MC02_IMU_BACKEND=quaternion_ekf|fusion`，默认 QuaternionEKF。固件只把所选后端源码加入显式清单，主机测试同时链接两个后端。
- 两后端共用源序号、接收时间、采样年龄、实测 dt、有效状态和参考版本。初始化后参考版本非零，每次成功重新初始化递增。
- QEKF 保留原噪声参数并沿用公共20ms预测期限和样本年龄限制；Fusion 用时间限制预测有效期，不声称拥有协方差上限。
- 加速度缺失、过期、模长不合要求或方向被拒绝时只进行陀螺预测，不续期校正时间。为避免上游 Fusion 叉积残差把完全反向向量误判成零误差，适配层在进入上游前补充点积方向门控；不发布上游超时后的强制量测恢复。
- 内部数值计算错误后实例保持无效，须显式重新初始化；单份坏输入不会写入滤波历史。INS 使用同一后端输出，失效时仍撤销许可、清控制快照并关热。

## 验证记录

- WSL 主机 Debug、Release 全量测试各 **373/373** 通过；姿态后端及 INS 生产路径的 ASan／UBSan 定向测试 **15/15** 通过。涵盖两后端单位和实测 dt、有限预测期限、质量拒绝、异常输入、实例隔离、参考版本、重新初始化及 INS 失效关热路径。
- ARM GCC **10.3.1** 的 bench_safe Debug 默认 QuaternionEKF 与 Fusion 配置均构建成功。默认 ELF 不含 Fusion 符号，Fusion ELF 包含 `FusionAhrs*`；两份 `mc02-selected-sources.txt` 只登记实际选中的后端。编译参数使用 Cortex-M7、`fpv5-d16` 和 hard-float，未启用 fast-math。
- `arm-none-eabi-size` 的可复核结果：QuaternionEKF `text/data/bss/dec = 213,192/3,468/127,224/343,884 B`；Fusion 为 `226,544/3,468/127,224/357,236 B`。按 `text + data` 计入 Flash 映像，分别为 **216,660 B** 和 **230,012 B**，Fusion 增加 **13,352 B**；`.log_workspace` DTCM 段两者均为 **14,656 B**，`.data` 和 `.bss` 相同。
- `MC02_IMU_BACKEND=invalid` 的独立配置检查按预期以“必须是 quaternion_ekf 或 fusion”失败。编译清单保留严格格式告警。
- 本轮时间验证覆盖输入采样 `dt`、样本源时间、过期边界和预测期限；没有测量 MCU 上的算法执行时间或 WCET。固件构建仅证明编译与链接，不代表目标运行性能。
- 未连接开发板。姿态精度、噪声适配、动态运动表现和物理执行耗时均未验证。
