# MC02-0072：统一电机输出轴单位与可信反馈

本页记录 MC02-0072 的实现和软件验收证据；唯一任务状态由 [.Doc/TODO.md](../../../.Doc/TODO.md) 维护。

## 行为与边界

- DJI、HT04 和 LK9025 的角度／速度闭环参考、反馈及 PID 输入统一使用输出轴坐标 `rad`、`rad/s`。转子测量按配置的减速比和方向转换；应用层把云台角度、底盘轮速及拨弹盘角度在驱动边界前换算为相同单位。
- 电流、力矩和电压保持各设备的原始数值类别，不借字段名称推断 SI 单位。直接电流或力矩输出不套用角度方向变换。
- `MotorFeedbackGetCapabilities()` 提供驱动能力信息；不支持的反馈或控制模式在注册前拒绝。`Motor_Output_Axis_Config_s` 明确描述转子／输出轴减速比和安装方向。
- 外部反馈及前馈使用只读快照回调。快照带数值、单位、参考系、采样时间、非零序号和有效标记；驱动核对单位、参考、有限值及最大年龄后才使用。回调返回快照本身不提供跨任务同步，发布者仍须使用合适的同步方式。
- DJI 首个有效单圈样本只建立多圈位置基准。若反馈中断使跨圈数无法可信恢复，内部多圈角度失效，内部角度环拒绝输出；显式调用 `DJIMotorRebaseReference()` 重新建立参考后恢复。外部角度源按其自己的期限判断。
- DJI 逐帧滤波默认值保持兼容：速度 `alpha=0.85`，电流 `alpha=0.9`。逐通道时间常数滤波继续使用实测采样间隔；每实例配置与历史相互独立。
- 应用 PID 增益按新输入／输出单位映射作数值换算，目标是保留现有软件命令尺度；这不能代替真实机构上的重新整定。

## 验证

主机测试使用生产电机驱动、PID、CAN／Daemon 接口或相关生产算法，硬件时间、HAL 和必要调度边界由测试替身提供。覆盖能力拒绝、转子到输出轴单位转换、外部快照单位／参考／时效、首帧建基准、间断后拒绝多圈控制、显式重建、DJI 默认滤波、HT04/LK 串级闭环及应用层参考换算。

- WSL Debug 和 Release 全量 CTest：各 `354/354` 通过。
- ASan／UBSan 电机相关测试：`51/51` 通过，覆盖能力与快照、PID、DJI 滤波、LK、HT04、INS、底盘和拨弹盘用例。
- ARM GCC 10.3.1 十种禁热配置构建通过：`bench_safe`、`rcdiag`、robot single/chassis/gimbal 各自 Debug 与 RelWithDebInfo。十种固件的配置隔离检查通过；六种 robot ELF 在最终增益配置后重新构建并复核通过。
- 编译参数使用 Cortex-M7、`fpv5-d16`、hard-float；未启用 `-ffast-math`。
- 与基线同工具链的链接区比较：DTCM 均为 `+0`；静态 RAM 和 Flash 变化如下。RAM 列为链接脚本 RAM 区占用差值，不把它解释成运行时峰值。
