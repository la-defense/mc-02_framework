## 协议门槛

电脑→DT7 的 USB 串口协议，与 DR16→MC-02 的 18 字节 DBUS、视觉 SP 43/29 字节都是不同协议。官方手册证明整条键鼠链路存在，却不能据此直接把 DBUS 发给 COM4。需核实本机设备/驱动/固件适用性、串口配置、握手、结构、校验、键位和周期，用官方原始实现或受控通信记录保存正确向量；全松开、W/E/F、鼠标移动和按钮逐项板上核对后才开发持续发送。

独立协议不足时停止调查、不发猜测包、不以官方客户端自动操作代替工具。官方客户端可用于查证/抓包。DT7 的固件版本仍待确认；已装 DJI Assistant 的版本不代表 DT7 版本。

## 2026-10-10：电脑端协议与有限动作通过

官方客户端原始程序集、22 字节帧、921600/8N1、CRC 初值与查表、键位、约 33ms 周期及无额外握手的依据见[协议调查](MC02-0049-协议调查.md)。归档 SHA256 为 `e45303baf581bbe803791440319abeaa9db613e57890627295354a2e7c3cd11d`；实际 DLL 为 5.0.2.37，不把官网 5.0.2.33 条目文字当二进制版本。没有运行官方客户端或刷 DT7 固件。

在用户确认左上/右中、USB 已接后，精确核对 COM4 VID_FFF0/PID_0008/serial=0001A0000000。使用诊断固件 `5c64ed0` 的匹配 ELF，逐项只发送一个官方向量，再发送一个全松开；成功写入 22 字节并只读核对板上字段及释放。全松开、W=1、E=128、F=512、X=120/Y=-40、两按钮、A=4、D=8 共九项全部通过；E/F 各增加一个边沿，松开后键鼠字段均零。固定 33ms 持续功能只在这些对照通过后开始实现。

原始发送时间/字节、设备、期望值及动作前/动作中/松开后快照在 `build/flash-tools/dt7-once-20261010-*.json`；仅 18 次 COM4 写入，向 COM14 写入 0 次。一次性脚本 `build/dt7-protocol-once.py`；源向量与静态提取在 `build/dt7-protocol-research/`。目标持续 running，状态 SAFE/使能零；整个阶段的 IMU/寄存器/SP 证据也在 R25-06 采集会话中。

本机验证了该实现对当前 DT7 的适用性，仍未读取遥控器内部固件版本。原始位图 A/D 的实测和官方键位一致，当前固件宏/位域却反置；生产 UART/遥控/daemon 解析回归先在 A=0x0004 的 `.a` 断言失败（`build/mc02-0049-map-red.log`），交换 A/D 宏与位域后通过（`-map-green.log`）。不在工具中补偿错误；SP 和参数格式不变。MSG-05 的其他字段与单位仍保留原有核查范围。

## 工具、运行方式与验收约定

实现文件 [dt7_input.py](../../../tools/dt7_input.py)，示例 [dt7_bench_replay.json](../../../tools/examples/dt7_bench_replay.json)。Windows 依赖 Python、pyserial、Tkinter；现有主机已具备。默认执行只列设备；发送需显式端口，并匹配已验证的 VID/PID/序列号。示例只供裸板诊断，真实执行器不可连接。

```powershell
python -B tools/dt7_input.py
python -B tools/dt7_input.py replay tools/examples/dt7_bench_replay.json --dry-run
python -B tools/dt7_input.py replay tools/examples/dt7_bench_replay.json --port COM4
python -B tools/dt7_input.py live --port COM4
```

JSON 包含 `duration_s`（0–180 秒且非零）和按 `at` 递增的 `actions`，动作类型为 `key`、`button`、`mouse`、`release`。支持键位 `W S A D SHIFT CTRL Q E R F G Z X C V B`。鼠标使用窗口内像素相对增量，X 向右为正、Y 向下为正；不声称其灵敏度等同 Unity 原客户端。日志默认放 `build/dt7-input/`，也可显式 `--log`；拒绝覆盖旧文件。dry-run 使用虚拟时间快速编码，不枚举、不打开串口。

回放与实时共用编码、状态和发送/释放类。不自动重连；超时、短写、断连立即停止。每 33ms 最多发送一个当前状态，迟到不逐帧补发历史包。实时输入在窗口接收区操作；失焦释放并暂停，人工点击重新开始。鼠标累计相对增量成功发送后清零；长按维持状态，不重复按下边沿。

正常退出/失焦/Esc/关闭/Ctrl+C 共用全松开逻辑；失败只能记录释放未确认，不能宣称板子已清零。保存动作时间、原始发送字节、设备与错误。验证正常退出与拔 DT7 USB 残留分别取证；后者若残留，关闭 DT7 撤销并保存问题，任务不关闭。
