# MC02-0052：移除空发射反馈话题

任务状态只维护在 [.Doc/TODO.md](../../../.Doc/TODO.md)。本问题与 [R25-11](R25-11.md) 一起修复。

## 问题与修复

`shoot_feed` 没有有效载荷定义，但 `RobotCMDInit()` 曾以零长度注册该话题。消息中心拒绝零长度话题，使整机命令初始化失败。该话题也没有真实生产消费者或有效发布数据。

删除 `shoot_feed` 的命令侧订阅和无用状态，以及发射侧空话题注册/发布；不添加占位字段。发射状态不再通过该未定义路径传递，现有模式和安全控制逻辑保持原接口。

## 验证

- 生产 `RobotCMDInit()` 和 `ShootInit()` 正常初始化回归通过。
- WSL Ubuntu 22.04 主机 Debug/Release 各 99/99 CTest 通过。
- bench_safe、robot、遥控诊断六种禁热固件配置均构建成功，ELF 隔离检查通过；非法配置按预期被拒绝。
- 未烧录；本项是软件初始化修复，实机执行器行为仍由台架任务验收。
