# MC02-0006 + MC02-0007：IMU 样本时间与加速度传输

基线：`547fb799673905171aa1ea5c1032ee0eee071637`。实现位于共用分支`feat/master-machine-imu-sample`。

## 实现范围

- `VisionIMUSample_t`在INS和master_machine之间保存BMI088有效位、样本序号、本机毫秒采样时刻及原始三轴加速度。单位为m/s²，轴向为BMI088传感器x/y/z，包含重力，尚未做机器人安装方向修正。
- V2类型`0x84`使用17字节小端负载：有效位、非零`uint32`样本序号、三个binary32加速度值。帧头`source_time_ms`传递样本时间，时间0合法。无效状态要求有效位、序号、三轴和帧头来源时间全零。
- INS在BMI088成功、源年龄不超过5ms且三轴有限时发布有效快照；采样失败、过期或非有限值时发布全零无效标记。该发布在EKF计算之前完成，因此原始加速度是否可用不依赖EKF是否校正成功。
- V2每50ms最多提交一帧，姿态、裁判摘要和IMU轮流发送，IMU名义上每150ms一次。发送前再次检查5ms源年龄。无样本、失效、超龄或消息中心记录过期时发送显式无效帧，撤销接收端可能保留的旧值。SP构建仍使用原29/43字节格式；不提供伪造的SP样本时间。

## 验证证据

- 固定V2帧独立字节答案覆盖有效标记、序号`0x11223344`、`1.0/-0.5/9.81 m/s²`、来源时间`0x01020304`及CRC；另测非法值、输出保留、容量不足、无效负载和`UINT32_MAX`序号。
- 生产链路测试经过`VisionUpdateIMUSample()`、消息中心、V2轮询和帧解码，覆盖初始化状态、空参数、非法序号/NaN/Inf、零时刻发布、失效撤销、5ms边界、6ms失效、毫秒时钟回绕、样本序号`UINT32_MAX→1`及本地快照过期。
- INS生产任务测试覆盖原始有效值、采样失效撤销，以及EKF或陀螺仪路径失败时原始加速度仍独立发布。
- WSL全量Debug与Release CTest各`365/365`通过；新增协议、生产链路和INS测试另以ASan/UBSan运行通过。Release最后一次全量结果应与代码提交SHA一致；具体提交见Git历史。

## 边界与后续

本轮只验证下位机协议编码、消息传递、失效标记和固件构建。没有实现生产上位机的序号去重／乱序处理或单位显示，没有开发板传输、传感器安装轴向和物理加速度精度验证。消费端可用回绕安全的序号差识别重复与旧样本，并结合MC02-0090时间映射解释帧头本机时刻；控制输入仍以本机接收时间为准。
