# 哨兵近期软件交付路线

本路线按用户确认的“近期本机验收、中期硬件验收”推进。任务状态只在[TODO](../../../.Doc/TODO.md)维护；本文说明实施顺序、依赖和完成条件，不维护第二份进度表。

## 使用方法与边界

继续本目标前，读取 TODO、当前分支及最近票据证据，选择以下顺序中第一个依赖满足的软件切片。每批完成实现、必要验证、教学说明和本地中文提交后继续下一批。真实参数缺失时记录具体缺项，先处理可独立验证的软件，不将测试参数写入生产确认项。

实车结构为单 MC-02、四轮全向轮，机械链为底盘→大 yaw→小 yaw→pitch。大 yaw 可连续多圈，IMU 随 pitch 俯仰。首阶段现场验收为底盘和云台无弹运动，发射机构关闭。本目标期间只进行本机工作；上板、上车及发射等待现场条件确认。

原 `bench_safe` 继续禁热、禁火和禁止执行器动作。新增受限上车调试配置与它分别命名；正式 `robot` 仍要求完整机械配置和三轴能力确认，不能为取得构建产物而绕过这些条件。

## 近期第一批：受限调试、输入与许可

| 项目 | 任务关联 | 本机完成条件 |
|---|---|---|
| 独立受限上车调试配置 | MC02-0144、0054、0026 | 独立构建身份和模块选择；默认失能，仅人工新鲜输入显式使能；发射关闭；未确认的启用执行器参数拒绝，未启用模块无注册和周期调用 |
| 输入适配与手动控制 | MC02-0003 | 协议合法输入转换为 SI 单位、明确参考系和源期限的意图；连续目标与有期限事件分开，不因重复转换续期 |
| 单板模式与功能许可 | MC02-0056 | 单一管理者发布整车与功能许可；手动／辅助／自主来源明确，辅助人工击发；急停、标定、任务和核心反馈失效立即禁止；恢复只接受新输入 |
| CAN及反馈失效 | MC02-0047、R25-04 | 错误与 BusOff 撤销旧控制及未提交队列，恢复要求连续有效反馈和新命令；主机注入证明软件撤销，不声称物理停止时延 |

调试配置的人工作用只来自遥控／键鼠有效输入，不接收视觉或导航的运动授权。实现复用正式模块及依赖检查，按模块能力拒绝缺项，不将整个生产检查改成宽松模式。具体电流、速度、限位和变化率均来自已确认配置；没有数据时软件测试使用隔离测试配置，实际运动配置保持拒绝。

## 近期第二批：调度、配置、底盘与三轴

| 项目 | 任务关联 | 本机完成条件 |
|---|---|---|
| 独立任务与平台周期唤醒 | MC02-0055、0088 | 周期启动读取、运行固定；计算／发送分别配置；创建失败、非法周期、分辨率、跳拍与超期有明确处理；控制计算留在任务内 |
| 参数来源与检查 | APP-10、PARAM-03软件部分 | 机械／电机／限位数据唯一来源，单位和关联检查明确，错误不改旧有效配置；实测数值仍待现场 |
| 底盘接口与反馈 | MC02-0057软件部分 | m/s、rad/s、前左上坐标；参考系转换、全向轮正逆计算、实际速度和可选本地里程计；来源失效撤销依赖命令 |
| 三轴与自旋协调 | MC02-0058软件部分 | 纯手动控制整体枪口方向；搜索、锁定回中、局部重捕获、全局扫描状态完整；大 yaw 使用实际底盘转速补偿；配置偏置正弦及移动降自旋，饱和可请求降速 |

安装几何、轴零位、轮组参数、范围和控制周期缺项须明确列出。坐标计算和状态机可以用测试输入验证；算法通过不等于实车稳定性、速度精度或任务实时性通过。

## 近期第三批：视觉补偿与发射软件

| 项目 | 任务关联 | 本机完成条件 |
|---|---|---|
| 视觉前馈与有限外推 | MC02-0091 | 同步有效且参考时刻明确才补偿；不续期，角速度／角加速度到控制量转换匹配物理量，启停／越界／失同步可验证 |
| 发射就绪与请求管理 | MC02-0059 | 单套机构、可配置摩擦轮数量与型号；全部反馈有效且稳定到速才供弹；未就绪单发拒绝，连续发射使用当前有效授权 |
| 卡弹与有限恢复 | MC02-0027 | 检测、反转、失败停用和按间隔有限试运行；失败只影响发射，旧请求不重放 |
| 裁判限制 | R25-15软件部分 | 请求射速保持，热量不足或机构未就绪暂停；功率／缓冲／供电许可分别检查新鲜度，失效不延用额外功率 |

视觉决定自动击发时机，下位机检查基础许可、核心反馈、裁判与机构条件。上位机生产适配涉及另一仓库时，在对应 TODO 登记关联任务；本仓库测试帧仍禁火。发射软件主机测试不驱动机构。

## 中期：现场条件确认后验收

1. 板级静态：0054／0128／0067相关部分，验证真实启动、供电、中断／DMA、复位输出和 CAN 过滤；记录备份、固件身份及参数区保留。
2. 实车静态：APP-10／R25-08／PARAM-03，确认型号、总线／ID、轮序、方向、减速比、几何、IMU安装及三轴零位／范围。
3. 逐电机与停止：确认低输出范围后核对方向，验证急停、遥控失联、反馈过期、CAN异常和恢复；实际停止时限由测量取得。
4. 无弹运动：架空轮序后低速前进、横移、自旋；逐轴限位后整体枪口控制、回中、扫描、自旋补偿与目标跟踪。
5. 时序与自主：测量任务周期／抖动、总线负载、上下位机时延和计时连续性，验证有效裁判阶段、链路中断和新命令恢复。
6. 发射后续：先无弹摩擦轮／拨弹联动，再另定受控发射条件；检查弹速、热量、功率及真实解堵表现。

MC02-0142 的回绕算法可近期验证，目标上的统计连续性仍需板测。Cache／MPU、F407、C++试点、CORDIC／FMAC及无实际需求的新设备后排；性能调整以测量为依据，不恢复既有六个暂缓主题。

## 统一交付条件

使用 WSL Debug／Release、必要的 ASan／UBSan、受影响 ARM 构建与源码／ELF检查；复用已有测试，仅为新增行为补必要回归。每次提交至少实质更新一份对应教学文章及索引，证据写入对应票据 evidence 目录。

软件与现场混合任务只记录软件部分完成，完整 TODO 继续开放至全部原验收条件满足。当前生产哨兵拒绝构建的原因、缺失的实车参数和未测的实际时限均保留在交付记录中。
