# TB47S 裸板供电安全审查

## 用户要求和接线

用户要求审查整个 MC-02 工程，判断 24V／6S 上电测试是否能保证绝对安全。
已确认使用 DJI TB47S 智能电池，经 XT30 接主输入；仅连接开发板、LCD、电脑 USB 和调试器，没有电机、电调、舵机或发射机构。调试器不向板供电，由板向调试器供电；没有外部可设置的限流。

## 审查约束

- 审查源码基线为 `0965d031ad60c5f1c1eeeac63c728dc44f7d4338`。源码版本和板上固件版本分开记录，不推定一致。
- 核查启动、GPIO／PWM、电压与温度采样、加热、状态机、RTOS／看门狗、异常／调试、参数写入、USB／视觉、LCD 及执行器初始化的安全路径。
- 从官方手册、原理图和芯片资料核实硬件事实，区分原理图、实物和待核验信息；不把 MCU／DC-DC 的单器件额定值当成整板允许电压。
- 根据用户的实际接线给出明确结论、风险证据及受控测试的前提。不能承诺绝对安全，也不能把未做的硬件测试记录成通过。
- 本次交付审查报告、硬件来源记录、TODO 更新和相关学习资料。运行固件及协议格式保持当前基线；不执行上电、烧录、停核、复位或控制发送。
- 新缺陷使用稳定任务 ID，已有任务补充证据与验收条件；任务状态仅存放于 `.Doc/TODO.md`。
- 完成文档检查及必要的现有主机测试，提交后进行 Standards／Spec 两轴审查。

## 验收

1. 报告可追溯到源码位置和可信硬件来源，覆盖上述安全路径。
2. 明确说明当前无限流电池直连不能获得安全放行，并给出实际阻断原因。
3. 区分当前已存在的保护、可证明的代码缺口、条件计算和尚未核验的实物情况。
4. 发现的问题有 TODO ID、类别、状态和可观察的完成判据，相关学习笔记可从索引找到。
5. 交付 Git 提交，说明验证结果、未执行的硬件动作和下一步前提。
