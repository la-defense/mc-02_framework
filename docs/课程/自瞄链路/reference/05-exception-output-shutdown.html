MC-02 安全联调 · 速查

异常关断与栈帧

顺序：直接关输出 → 读故障寄存器 → 验证栈帧 → 保存现场 → 复位。重复异常只走关断与复位。

直接关断对象

信号动作代码
PB1 / TIM3_CH4先把 ODR 锁存为低，再切 GPIO 输出；清 CCR4、CC4E、CENBSP_SafetyLatchOutputsOff
PC13、PC14、PC15BSRR 拉低，再配置为低速、推挽、无上下拉输出受控 24V / 5V 使能脚

该动作是软件请求。它不等同于测量板上引脚电平、外部供电轨或外接设备响应。

EXC_RETURN 与核心帧

位含义用途
bit20=MSP，1=PSP选取异常压栈指针
bit41=基本帧，0=浮点扩展帧扩展帧核心 R0 从 SP+0x48 开始
其他位必须属于 Cortex-M7 定义的 EXC_RETURN 值无效值不读帧

基本帧 8 个字；浮点扩展前缀 18 个字，总计 26 个字。核心帧起点及完整读取范围必须留在一段链接脚本映射的片上 SRAM 内。

拒绝读取的 CFSR 栈错误位

  • MemManage：MUNSTKERR bit3、MSTKERR bit4、MLSPERR bit5。
  • BusFault：UNSTKERR bit11、STKERR bit12、LSPERR bit13。
  • 异常帧需 8 字节对齐；地址、帧长度、EXC_RETURN 或 CFSR 任一不可信时，不解引用帧和异常栈快照。

整机调度停摆

整体调度停摆时，IWDG 会复位目标，软件关断在重启后的 main() 最早用户初始化步骤执行。调用恢复进入前的 PRIMASK；复位向量至 main() 之间的引脚状态仍未完成物理验收。

本地验证

cmake -S tests/host -B build/host-tests -G Ninja
cmake --build build/host-tests
ctest --test-dir build/host-tests --output-on-failure

重点测试：寄存器关断写入、基本/扩展帧及范围拒绝、任务监控故障先关断再记日志。 Error_Handler 关断测试、异常重入复位测试。

主要资料：Arm Cortex-M7 用户指南、ST RM0468。课程入口：异常先关输出。
