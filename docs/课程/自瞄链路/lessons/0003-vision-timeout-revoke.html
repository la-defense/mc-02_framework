视觉超时与撤销控制

本课目标：从“上一次收到了好指令”推理到“现在仍允许执行”。

有效性会随时间消失

一帧 CRC 正确，只能说明它在到达时通过了格式检查。链路断开后，内存里的 yaw/pitch 仍然有数值，但那只是旧命令。控制判断还要检查最近一次有效接收的年龄、模式、数值是否有限，以及角度是否落在已配置的机械范围内。

有目标且数据新鲜时，主机可以发送控制模式 1 的瞄准帧。本机裸板联调还要强制关火。无目标、数据过期、串口断开或程序退出时都发送中立帧；若链路已经断开无法发送，MC-02 的视觉超时处理要清除旧命令并禁能。

有效的新目标 → 控制模式 1 / fire=false
无目标、过期、NaN/Inf、越界或断链 → 中立模式 0 / fire=false

试着回忆

  1. CRC 正确的旧帧为什么不能永久保持“在线”？
  2. 通信已经断开，为什么还需要下位机自己的超时撤销？
核对答案

CRC 不包含“当前还新鲜”这个事实，因此状态必须按接收时间过期。链路断开时上位机无法发送中立帧，所以下位机必须自行清除旧控制。
