约定：凡是你提出"为什么 / 这是怎么回事 / 有什么区别"这类问题，我都会在这里补一篇编号文档，并更新本索引。

**流程约定（2026-09-22 起）**：每完成一项任务后，我会回顾本次用到的技术栈并补一篇学习文档；
如果某个技术栈**在本目录里已经有专门文档，就合并进那篇**（补充新踩的坑与实测数据），不重复开新篇。

## 阅读顺序建议

1. 先读 01，理解"为什么同一个固件换个编译参数就快一大截"；
2. 再读 02，理解我们实测出来的 `IDLE 5.9% / motor 48.2% / ins 35.7% / lcd 8.9%` 各代表什么；
3. 最后看审查报告里"CPU 饱和排查"章节的改造前后对比表，把数字和原理对上。
