# 学习笔记（索引）

这个目录放的是"概念讲解 + 本工程具体怎么做"的入门文档，面向**知道怎么写代码、但不想读编译器手册**的读者。
你提出"为什么 / 这是怎么回事 / 有什么区别"这类问题时，讲解材料也在这里维护；已有主题补充原篇，新主题才新增编号文章。

**流程约定（2026-10-08 更新）**：每次改动都必须提交至少一份新增或实质更新的教学文档，包括代码、配置、文档和工作流改动。
已有主题更新原篇，补充改动原因、工程例子、验证方式与局限，并引用任务编号和相关代码；没有对应主题才新增编号文章。教学文档随改动交付，跨仓库使用关联提交。teach 按需使用，写出文档不等于已经掌握。

## 阅读顺序建议

1. 先读 01，理解"为什么同一个固件换个编译参数就快一大截"；
2. 再读 02，理解我们实测出来的 `IDLE 5.9% / motor 48.2% / ins 35.7% / lcd 8.9%` 各代表什么；
3. 最后看审查报告里"CPU 饱和排查"章节的改造前后对比表，把数字和原理对上。
