# SeaSky A5 历史参考

本目录保存旧 A5 串口编解码源码、头文件和协议资料，供查阅旧帧格式及兼容测试使用。当前视觉链路采用 SP 固定帧；本目录不属于固件源文件收集范围，也不是可选通信后端。

## 旧帧格式

旧帧以 `0xA5` 开始，依次包含两字节数据长度、CRC-8、两字节消息编号、两字节标志、原样复制的 `float` 数据和两字节 CRC-16。长度以字节计，CRC-8 使用 `CRC8_CAN_A5`，CRC-16 使用 `CRC16_MODBUS_A5`；两者均由当前统一 CRC 模块计算。历史兼容向量为：

```text
a5 06 00 99 45 23 34 12 00 00 80 3f 78 7b
```

它表示消息编号 `0x2345`、标志 `0x1234`、一个 `1.0f`，整帧14字节。逐字节答案由[历史兼容测试](../../../tests/host/crc_a5_test.c)固定。

## 使用限制

头文件中的旧解析入口没有接收字节数和输出容量参数。解析代码会按帧内声明长度读取并复制数据；调用前若不能确保完整帧及目标容量，可能越界访问。因此不要将归档解析器接入活动接收链路或用于未经检查的外部数据。

旧协议说明仍显示早期 `void get_protocol_send_data(...)` 签名，而同目录归档头文件记录后续 `CRCStatus_t` 版本；两者反映不同时期，不能拼成统一的现行接口契约。F4 硬件 CRC 等待办也仅为历史内容，不表示相关设想已实现。主机测试会显式编译归档源码以验证旧帧字节；固件 CMake 和 Makefile 均不收集这份源码。
