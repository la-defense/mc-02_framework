# 标准命令

`StdCmdAdaptManual()`将上游已合法解码的摇杆或键鼠通道换成统一运动意图。输出依次为底盘前进／左移速度（m/s）、底盘自转、枪口整体yaw和pitch角速度（rad/s）。它不解析协议、不选择模式，也不授予电机或发射许可。

车型为每个通道提供原始范围、有符号换算比例和输出幅值上限。原始输入越界直接拒绝；合法输入换算后才按输出上限限制。死区和响应曲线继续归输入来源模块，不在这里重复处理。

输入携带原始来源时间、来源序号和期限。原始时间必须已经属于本机毫秒时钟；结果保留时间和序号，期限取来源与映射配置中的较小值。重复换算不能延长使用时间。任何失败保持原输出，调用者须根据返回结果撤销该来源，不能因为内存还存着旧值就继续使用。

`StdCmdConsumeEvent()`只判断按次事件是否新鲜且未消费，不解释动作或授权。每个来源独立保存32位序号，零保留为未收到，向前范围小于半个32位计数区间；不复用遥控旧接口的8位累计次数。一个消费者持有并更新游标，源重启后的序号重建需由后续来源接管流程明确处理，不能在每次超时后随意清零去重记录。

本轮先建立纯C接口和主机行为检查，尚未替换 RobotCMD 的旧固定系数与命令来源选择。实际接线、三模式仲裁及安全许可由 MC02-0003／0056 后续切片继续；默认固件的活动源码仍不包含这个尚未接线的模块。测试参数不进入哨兵生产配置。
