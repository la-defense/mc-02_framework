# LCD 模块

本模块由 `lcd.c` 控制面板初始化、SPI1 阻塞发送和故障状态；`lcd_buf.c` 使用固定单行 RGB565 缓冲绘制；`lcd_ui.c` 绘制四页界面；`lcd_task.c` 负责按键、刷新和既有恢复触发。字形编号及字库由 `lcd_font_cn.h/.c` 提供，字库来源说明保留在字库文件中。

## 初始化与调用

板级代码先初始化 LCD GPIO、SPI1 和 HAL 毫秒时基，再由单个普通任务串行调用 LCD 绘图和 UI 接口。先调用 `LCD_UI_Init()` 建立整屏内容；绘图接口不保存传入数组地址，ASCII 和中文字形按显式长度读取。系统不创建 LCD 专属堆对象，也不分配全屏帧缓冲。

横屏绘图区为252×212像素，矩形坐标包含两端。ASCII仅接受可打印的 `0x20～0x7E` 字节和12／16像素字高；中文接口接收字形枚举及数量，不解析 UTF-8。两者都先检查完整输入和屏幕区域，再开始发送。RGB565 像素仍按既有硬件字节顺序传输。

数值接口覆盖 `int32_t` 全范围；浮点格式化接受有限值、小数位0～3，并采用最近值、半数远离零的舍入。界面文本按当前行宽缩短并显示 `~`；无效动态数值显示 `--` 和原单位。

## 超时、失败与恢复

每次 HAL SPI 发送的超时最多2ms。面板初始化／完整恢复总预算1000ms，清屏和静态页250ms，数值更新20ms；嵌套绘图共用顶层预算，HAL等待期间持有 tick lease。预算受调度影响，不代表严格截止时间。

发送错误或超时会停止后续绘制、抬高片选、关闭背光、让界面不可用并使行缓存失效。`LCDGetState()` 只复制状态，不发送或恢复。后续刷新不会反复访问面板；现有长按中键和稳定重新接入事件可各触发一次完整恢复。SPI 停止无法确认时模块保持隔离，需系统重新初始化。成功状态只说明 MCU 已完成 SPI 发送，不代表面板已确认显示。

## 本机与实物验证

主机测试链接生产绘图、UI 和裁判行代码，替身只提供 HAL、时间和板级数据；固定答案检查几何、字模、RGB565 像素、数值格式、缓存和失败恢复。ARM 固件使用 `lcdtest-debug` 构建可选的四页 LCD 诊断；它只允许禁热 `bench_safe/single`，不创建额外任务，按每页15秒展示四种测试内容后回到普通页面。实物显示、按键和背光恢复需依照 [MC02-0097任务记录](../../docs/workflow/tickets/MC02-0097.md) 完成并记录。
