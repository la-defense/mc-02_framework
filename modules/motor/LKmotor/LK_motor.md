# LK 电机模块

本文说明本工程 LK9025 驱动的注册、闭环反馈选择和多电机发送约定。电机协议字段以对应型号的官方说明为准；本机回归只验证 MCU 侧的软件计算、注册与组帧，不验证电机实际响应。

## 电机编号与 CAN ID

调用 `LKMotorInit()` 时，`can_init_config.tx_id` 用作电机编号，允许范围是 **1～4**。它不是最终 CAN 发送 ID。每条物理 CAN 总线最多注册四个实例，可以稀疏、乱序注册；同一总线的编号不能重复，不同总线可以使用相同编号。

所有实例都接收反馈 ID `0x140 + 电机编号`，并使用 CAN 发送 ID `0x280`。编号独立保存在 LK 实例中，组帧时固定映射如下：

| 电机编号 | 命令帧字节 | 反馈 ID 示例 |
|---:|---:|---:|
| 1 | 0～1 | `0x141` |
| 2 | 2～3 | `0x142` |
| 3 | 4～5 | `0x143` |
| 4 | 6～7 | `0x144` |

输出值按有符号16位值的二进制补码编码，低字节先发。浮点结果非有限或经过方向处理后不能表示为有符号16位命令时，本轮记为数值失败、清除 PID 历史并把对应槽位置零，不对电流命令做饱和猜测。空槽、停止实例和其他本周期控制计算失败也保持对应字节为零。各总线先独立构造完整八字节帧，再由该总线首个成功登记的实例提交一次；一条总线提交失败不会阻止其他总线发送，也不会缓存失败帧等待重放。

## 初始化与失败回退

LK 注册只允许在启动阶段串行完成，并且要早于 CAN 接收派发、Daemon 和电机控制任务运行。驱动先检查配置类型、受支持的 CAN 句柄、电机编号、重复项和总线容量；随后在栈上验证启用 PID 环的参数，再依次准备 LK 对象、Daemon 和 CAN 接收注册。

配置由 `const` 指针传入，注册不会改写它。Daemon 失败时释放 LK 候选对象；CAN 注册失败时先注销 Daemon，再释放候选对象。只有 CAN 注册成功后才发布 LK 实例、发送对象和总线计数，所以失败不会留下悬空回调或占用 LK 槽位。成功实例没有运行期注销接口，相关对象会保留到复位。

`LKMotorControl()` 的返回类型仍是 `void`。是否成功把帧交给 MCU 的 CAN FIFO，由现有 `CANGetTxStats()` 统计；该结果不表示总线上收到 ACK，也不表示电机已执行命令。

## 闭环反馈与前馈

角度分支在 `outer_loop_type == ANGLE_LOOP` 时运行：`angle_feedback_source` 选择内部 `measure.total_angle`（deg）或调用方外部角度值（deg），并由 `angle_PID` 计算。速度分支在外层配置含角度或速度位且速度环启用时运行：`speed_feedback_source` 选择内部 `measure.speed_rads`（rad/s）或外部速度值（rad/s），并由独立的 `speed_PID` 计算。电流环使用本机 `real_current` 及 `current_PID`。

速度前馈沿用原位置，在角度 PID 之后加入；当前输出前馈沿用原位置，在速度 PID 之后、当前 PID 之前加入。只有该分支会实际读取的反馈和前馈指针才要求非空；其余指针可留空。指针指向的值在控制轮次中各读取一次，调用方需保证存储持续有效。外部共享数据的跨任务同步仍由 R25-14 跟踪。

初始化只检查实际会运行的 PID 配置。若之后通过公开实例字段切换到未初始化 PID，或反馈来源枚举、指针、数值变为无效，控制轮停止后续计算，将该电机槽位写零并清除三环历史；恢复合法数据后，下一轮可重新计算。总角度的初始参考和跨圈可信度仍由相关 LK TODO 跟踪。控制公式及主机数值回归见 [LK9025.c](LK9025.c)、[LK CAN 集成测试](../../../tests/host/lk_motor_bsp_can_test.c) 和 [MOTOR-01/02 记录](../../../docs/workflow/tickets/MOTOR-01-02.md)。

主机回归还覆盖固定串级数值、四种内部／外部反馈组合、独立 PID、两种前馈单独及组合、非法来源、非有限输入、前馈溢出与恢复；测试链接生产 `LK9025.c`、PID、Daemon 和 BSP CAN，仅替换 HAL、时间和日志。当前没有连接开发板或实际 LK 电机，因此不对物理链路、ACK、单位标定或电机性能作结论。
