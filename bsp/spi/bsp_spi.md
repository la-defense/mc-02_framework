# SPI 设备与独占收发

本模块为SPI1、SPI2保存设备配置和正在进行的收发。公开说明集中在[bsp_spi.h](bsp_spi.h)，实现见[bsp_spi.c](bsp_spi.c)。先初始化HAL外设、片选GPIO、DWT与HAL tick；同一物理总线运行时不能同时使用直接HAL和本模块。

## 注册与生命周期

`SPIRegister(const SPI_Init_Config_s *)`成功分配一个长期实例，失败返回NULL。两条总线合计最多4个设备；重复GPIO片选、同一物理总线使用不同HAL句柄、非法模式、超限期限、分配失败均拒绝。注册不启动传输。配置可在返回后释放，HAL句柄须长期有效。

注册／注销由启动流程串行执行，不与提交、查询或回调并行注销。实例字段仅由模块改写。`SPISetMode()`只能在本总线空闲时修改，配置中的期限不随模式变化；`SPIUnregister()`也要求本总线空闲，否则返回0。没有运行期强制释放或隔离恢复入口。

## 提交和结果

`SPITransmit()`、`SPIRecv()`、`SPITransRecv()`统一返回HAL状态，长度为1～255字节，只支持8位主机。接收和全双工要求双线配置；全双工发送、接收数组不得重叠。所有提交限普通任务且中断未屏蔽。

阻塞模式最多等总线1000μs，实际HAL等待参数为2ms；等待他人到期只返回HAL_TIMEOUT。IT／DMA遇忙立即返回HAL_BUSY。参数不符返回HAL_ERROR，计时暂停或HAL仍忙会拒绝。拒绝请求不改旧片选和接收信息。阻塞返回HAL_OK表示完成；异步返回HAL_OK仅表示已接受，不能立即读取或释放数组。

异步配置检查SPI中断已启用；DMA还要求本次使用的DMA1／DMA2 stream、Parent、方向、普通模式、字节对齐、内存递增和中断有效。不自动将DMA改成IT；引脚、IRQ处理函数、DMA可访问内存及缓存一致性仍由平台和调用方正确配置。本轮没有新增任何板级IRQ或DMA配置。

`SPIGetTransferState(instance, &state)`只复制数据，失败保持原输出：

| phase | 含义 |
|---|---|
| IDLE | 已注册，尚未提交 |
| ACTIVE | 提交中、传输中或成功回调尚未返回 |
| RECOVERING | 已发现错误或到期，等待任务停止 |
| SUCCEEDED | 成功结束，result为HAL_OK |
| FAILED | 停止已确认，result保留原始错误或HAL_TIMEOUT |
| ISOLATED | 停止失败，禁止本总线继续提交 |

异步数组只有在`buffers_released=1`后才可改写或释放，收到HAL_ERROR也须检查这一字段；失败接收数组可能已有部分字节，不能使用。阻塞模式不启动DMA或收发中断，返回后栈数组可以释放，即使总线因停止失败被隔离。

## 回调与超时

完成仅匹配当前HAL句柄、使用者和传输类型。纯发送不调用接收回调；接收和全双工只在成功后调用一次。片选在业务回调前拉高，占用保留到回调返回。业务回调要短且不阻塞，不得重入提交、改模式、注销或超时服务。回调通常在中断，也可能在提交尚未返回的任务中执行。

`async_timeout_ms=0`表示默认20ms，其他值允许1～INT32_MAX毫秒，注册后固定。`SPIProcessTimeouts()`由Daemon任务约每10ms调用一次，使用HAL毫秒时钟，`elapsed >= timeout`判超时。异步期间保留HAL tick lease，直到停止确认后释放；隔离时继续保留。轮询、任务调度及HAL停止另有耗时，不保证精确停止时刻。

错误中断只置状态。任务调用当前HAL版本的阻塞`HAL_SPI_Abort()`；只有确认SPI与本次DMA停止，清理外设／DMA标志及对应待处理中断后才释放。停止失败不重试，保留本总线与异步数组直至系统重新初始化；其他总线继续处理。错误和超时不调用成功接收回调。

空闲、类型不符或恢复期间的完成通知被忽略。HAL通知不携带事务编号，同类型的任意伪造旧通知无法独立识别；禁止调用方手动派发完成，安全复用依赖硬件停止和清理已完成。

## 当前调用点与验证

- BMI088的生产路径仅在SPI2阻塞收发，检查返回值后才复制样本；异步触发采样仍拒绝。
- LCD在SPI1直接调用HAL，WS2812使用其他外设。这些入口本轮不迁移，不允许与本封装并行操作同一总线。
- 旧 `modules/imu/BMI088Middleware.c/.h` 与 `BMI088reg.h` 已由 MC02-0054 删除；Git历史保留原实现，现行驱动位于 `modules/BMI088/`。
- CMake是当前唯一固件构建入口，bsp_spi.c由源码清单选择。
